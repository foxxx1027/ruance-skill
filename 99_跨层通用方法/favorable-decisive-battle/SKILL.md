# 执行有利决战，避免不利决战

## R — 原文 (Reading)

> "一切有把握的战役和战斗应坚决地进行决战，一切无把握的战役和战斗应避免决战，赌国家命运的战略决战应根本避免。"
>
> — 毛泽东，第二卷《论持久战》（抗日战争中的决战问题）

---

## I — 方法论骨架 (Interpretation)

- 把"决战"——一次可能改变全局的摊牌、一次押上重注的对撞——按把握程度分三类处置。
- 第一类：有把握的局部战斗 → 坚决打，不犹豫。
- 第二类：没有把握的 → 避免硬拼，宁可待机。
- 第三类：赌上全部身家/生存的"命运之战"（all-in）→ **无论胜算看似多高，都应根本避免**，因为它的后果不可逆。
- 战略的实质是：用一串有把握的局部胜利，逐步改变力量对比；而不是一次押上全部本钱去翻盘。
- 反直觉之处：宁可放弃可能的速胜、放弃"一次翻盘"的诱惑，也不做不可逆的生存性押注。
- 判断难点："有把握/无把握"本身来自估计，估计可能错——所以要留待机空间，不把估计等同于事实。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 拿破仑攻俄——俄军"避免决战、勇敢的退却"
- **问题**: 敌强我弱的第一、二阶段，敌方求我集中主力决战，我方硬拼处于不利。
- **方法论的使用**: 作者以俄军放弃并焚毁莫斯科、诱敌深入后大举反攻为范例，对应提出"有把握则决战、无把握则避免、赌国家命运的战略决战根本不干"。
- **结论**: 应避免不利条件下的决战，以土地换取时间。
- **结果**: 拿破仑军仅二万余人逃离俄国；作者据此主张"中国现在也应这样干"（出处：第二卷《论持久战》，及 c09）。

### 案例 2: 反对把局部胜仗当"准决战"
- **问题**: 平型关、台儿庄等局部胜仗后，出现轻敌、主张寻求"准决战"的急性病。
- **方法论的使用**: 作者以持久战的总判断加以校准——一时一地的胜利不等于可以发起决定全局的决战，反对把决战提前到不利时机。
- **结论**: 小胜不能代替全局判断，非有把握不应寻求决战。
- **结果**: 徐州战役并未成为"准决战"（出处：第二卷《论持久战》，及 c07）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对巨头占据主导的市场，初创纠结要不要倾尽全部融资，正面打一场"决定性"的价格战/对撞。
2. 要不要"一把梭哈"——把全部资源、现金、信誉押在一个新方向上。
3. 谈判或诉讼中，纠结要不要把关系彻底撕破、做一次总摊牌。
4. 已经投入很多、输了不甘心，想再赌一次更大规模的行动来"翻本"。
5. 在"小步快跑积累小胜"与"寻求一次决胜"之间做路线选择。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要 all in""赌一把大的""梭哈""拼了"
- "决一死战""一波翻盘""毕其功于一役""这次一定要分个胜负"
- "EN: all-in, bet the company, do-or-die, make-or-break, decisive battle, go for broke, swing for the fences, this is the hill to die on"

### 与相邻 skill 的区分

- 与 `两手准备`(u25) 的区别: u25 管"平时/行动之前怎样为最坏情况做准备"；本 skill 管"这一次摊牌要不要打"（按把握分类，尤其排除 all-in）。
- 与 `战略上藐视敌人，战术上重视敌人`(u24) 的区别: u24 是心态与判断的两层分离；本 skill 是行动层面的取舍。
- 与 `歼灭战优先`(u20) 的区别: u20 管"这一仗以什么为目标"；本 skill 管"要不要打这一仗"。
- 与 `层次转换`(u21) 的区别: u21 讲在局部制造主动；本 skill 讲避免不可逆的整体对撞。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别候选"决战"**
   - 完成标准: 把当前决策中"一次定输赢、后果不可逆"的选项单独标出来（哪些属于"毕其功于一役"的对撞）。

2. **评估把握**
   - 完成标准: 对每个候选决战，写出支持/反对"有把握"的具体依据，而不是只凭感觉。
   - 判停条件: 若某选项属于"赌上全部身家/生存"的一类，直接判为"根本避免"，跳至步骤 4，不再评估胜算。

3. **分类处置**
   - 完成标准: 每个候选都有一个明确归类——有把握（打）/ 无把握（避或待机）。

4. **把被避免的决战改写成局部积累**
   - 完成标准: 至少给出一条替代的、可逐步改变力量对比的局部行动路径（一串有把握的小胜），而不是"什么都不做"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 后果可逆、损失可承受的日常试验性决策——套用会变成不敢试错。
- ⚠️ 把"避免不利决战"变成永不出手的拖延借口——待机是为了等把握，不是为了不做决定。
- ⚠️ 把与人际/团队关系的正常分歧拔高为"生死对决"来套用本 skill——把分歧"无限上纲"成敌我对抗，会无端制造不可逆的冲突。

### 作者在书中警告的失败模式

- **拼命主义**（有进无退、惧失土地而硬拼）（第一卷《中国革命战争的战略问题》，ce10）：不顾条件硬打、死守一城一地，把勇敢异化为蛮干，"结果不但城和地俱失，军力也不能保存"——正是"避免不利决战"要防的反面。
- **速胜论**（第二卷《论持久战》，ce15）：把一时一地的强弱当作全局转折、希望速决、急于发起决战，"勉强行去，败军亡国，结果和失败主义者没有两样"。

### 作者的盲点 / 时代局限

- "有把握/无把握/赌命运"的判定依赖对胜算的估计，估计本身不可靠（units-merged u44 风险提示）。
- 军事"决战"类比迁移到商业需重新定义"决战"（同上）——否则容易机械套用。
- 该论断**绑定 1930–40 年代的物质与格局条件**（武器、通信、后勤），脱离条件直接迁移可能失真（BOOK_OVERVIEW §3 时代局限 1）。

### 容易混淆的邻近方法论

- 两手准备（向最坏可能准备）；战略上藐视敌人，战术上重视敌人（心态双层）；歼灭战优先（以什么为目标）；层次转换（局部主动 vs 全局不可逆对撞）。
