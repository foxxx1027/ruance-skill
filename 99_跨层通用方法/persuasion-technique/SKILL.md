# 表达与说服技术（写作者对照清单·看对象说话·摆事实讲道理）

## R — 原文 (Reading)

> 鲁迅答北斗杂志社问第四条："写完后至少看两遍，竭力将可有可无的字、句、段删去，毫不可惜。"；"射箭要看靶子，弹琴要看听众。"
>
> — 毛泽东，第三卷《反对党八股》

---

## I — 方法论骨架 (Interpretation)

这是一份可直接照做的"写与说"清单，目标是让话被对方听懂、接受，而不是自我表演。

- **先看对象，再定内容**："射箭要看靶子，弹琴要看听众"——动笔动口之前先弄清读者/听众是谁、关心什么、能听懂什么，据此决定讲什么、讲多深、用什么词。这一步是前置动作，不是修辞。
- **狠删**：写完至少看两遍（重要文稿不妨看十几遍），把可有可无的字、句、段统统删掉，"毫不可惜"。删的是冗余，不是意思。
- **不硬写、不生造**：写不出就不要硬凑；不要生造只有自己懂的词句。
- **用事实和道理说服**：解决认识分歧要靠摆事实、讲道理，以理服人，而不是靠装腔作势、吓唬人或强压。
- **先给刺激、再给路径**：先点出问题及其后果（让人感到必要），再给出怎么做（让人知道怎么办）——只刺激不给路是恐吓，只给路不刺激则无人行动。
- **让语言贴近生活**：向群众的活语言、外国语言、古人语言学习，使表达具体可感。

通用表述：好表达 = 先调查受众 + 删到干净 + 以事实道理服人 + 先让人感到必要再给人办法。

## A1 — 书中的应用 (Past Application)

### 案例 1: 鲁迅的四条写文章规则（写作者对照清单）
- **问题**：党八股空话连篇、生造词语、不加删改就发表。
- **方法论的使用**：作者从鲁迅《答北斗杂志社问》中抽出几条规则逐条讲解，并补充自己的操作（写完"至少看两遍"，重要的看十几遍、反复删改），同时要求"射箭要看靶子，弹琴要看听众"，语言向人民群众、外国、古人三处学。
- **结论**：形成一份可逐条自查的写作与表达清单。
- **结果**：给出"至少看两遍、删尽可有可无的字句段、写不出不硬写、不生造词"等可照做条目。（原文未展开某篇具体文章的修改过程）
- **来源**：第三卷《反对党八股》

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户写完一篇文章/方案/邮件，想知道"该怎么改、删什么"。
2. 用户要向不懂自己专业的人（如管理者、客户）讲清一个复杂方案，担心对方听不懂。
3. 用户的汇报、建议或提案讲了却没人买账，需要提升说服力。
4. 用户发现自己的稿子空话多、啰嗦、自我重复，想写得干净有力。
5. 用户在准备一次演讲、培训或沟通，想兼顾"让人重视"和"给人办法"。

### 语言信号 (用户的话里出现这些就应激活)

- "这篇东西还能怎么改／该删什么"（how should I revise this / what to cut）
- "对方听不懂我说什么"（they don't get it / how to explain this clearly）
- "怎么讲才能说服他"（how to pitch this / how to make it land）
- "我写的太啰嗦/太空了"（too wordy / too vague）
- "怎么让我的建议被采纳"（how to get my proposal accepted）

### 与相邻 skill 的区分（初稿）

- 与 `analyze-synthesize-four-steps`（分析—综合四步法，u15）的区别：那是把材料组织成"提出问题→分析→综合→给办法"的内容结构，本 skill 是遣词、删改与说服的技巧。
- 与 `anti-liberalism-checklist`（反对自由主义作风自检清单，u43）的区别：那是行为作风的负面清单，本 skill 是表达质量的清单。
- 与 `let-people-speak`（让人讲话，u51）的区别：那是"听"（决策前征集意见），本 skill 是"说与写"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先调查受众**
   - 写/说之前先弄清听众是谁、关心什么、能听懂什么（射箭看靶、弹琴看听众）。
   - 完成标准: 能用一句话说明"这篇/这次是说给谁听的、他要什么"。

2. **定内容与语言**
   - 据此选择要讲的内容、详略和用词，不堆无关内容、不生造词。
   - 完成标准: 列出要传达的 1-3 个核心点，且与受众关切对齐。

3. **用事实和道理**
   - 关键主张都用事实、数据或案例支撑，讲清"为什么"，不用强压、吓唬或空喊口号代替论证。
   - 完成标准: 每个核心点都有可核实的依据。
   - 判停条件: 若关键主张找不到任何事实支撑 → 先补证据，不要靠语气和篇幅硬撑。

4. **对照清单删改**
   - 至少看两遍（重要文稿可看十几遍），删尽可有可无的字、句、段；写不出不硬写。
   - 完成标准: 逐条过完清单，删掉的每一处都不影响原意。

5. **检查说服路径**
   - 先给刺激（指出问题及其后果），再给路径（具体怎么做）。
   - 完成标准: 受众能复述"问题是什么、我该做什么"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **需要严谨精确的法律、技术、合同文本**：口语化、删减过度会损害精确性；本清单主要用于沟通类写作。
- **把表达技巧用于整人式批判**：以"批判"为名行打压、羞辱之实，是本 skill 目的的反面。
- **口号式宣传/空话连篇**：只喊口号、不摆事实，正是本 skill 要治的病。
- **为迎合受众而放弃求真**："看对象说话"是调整表达方式，不是歪曲或隐瞒事实。

### 作者在书中警告的失败模式

- ce20 空话连篇、言之无物："懒婆娘的裹脚，又长又臭"，群众见了就摇头不肯再看。
- ce21 装腔作势、借以吓人：靠吓人战术取胜，对同志还大讲"残酷斗争、无情打击"——"对敌人是毫无用处，对同志只有损害"。
- ce22 甲乙丙丁、开中药铺：只按外部标志罗列现象、不分析内部联系，是最低级、最幼稚、最庸俗的方法。
- ce27 命令主义与压服、ce33 强加于人：对内部用强制手段、把自家做法硬塞给别人，都收不到说服效果。

### 作者的盲点 / 时代局限

- "摆事实讲道理"一条出自第 7 卷"静火版"，可靠度最低（BOOK_OVERVIEW 第 3 节·时代局限 4）。
- 文本倾向以二元对立（进步/倒退、我方/敌方）压缩选择空间，且易以立场标签替代论证，这与"摆事实讲道理"本身构成内在张力（BOOK_OVERVIEW 第 3 节·立场盲点 4）。
- "看对象说话"若操作过度，可能滑向迎合而非求真（units-merged u46 风险提示）。

### 容易混淆的邻近方法论

- `analyze-synthesize-four-steps`（分析—综合四步法，u15）：是内容结构方法，非表达技巧。
- `anti-liberalism-checklist`（反对自由主义作风自检清单，u43）：是作风清单，非表达清单。
- `let-people-speak`（让人讲话，u51）：是倾听与征集意见，非表达与说服。
