# 团队/委员会的工作方法（当好班长·弹钢琴·抓紧·胸中有数）

> **语境剥离说明**：本单元原文以"党委会""书记""委员"为组织术语，讲的是集体领导的工作方法。此处剥离其特定组织形态，改写为通用的**团队/委员会领导方法**——凡涉及领导集体、会议、分工的团队场景均可借用其"形"，不限定任何特定组织。

## R — 原文 (Reading)

> "要'抓紧'。……什么东西只有抓得很紧，毫不放松，才能抓住。抓而不紧，等于不抓。"；"胸中有'数'。……对情况和问题一定要注意到它们的数量方面，要有基本的数量的分析。"
>
> — 毛泽东，第四卷《党委会的工作方法》

---

## I — 方法论骨架 (Interpretation)

这是一套可照做的团队/委员会领导清单，核心是把"怎么带一个集体"从口号变成动作：

- **当好主持人（"班长"）**：领导者的角色是把这一班人带好、把会议主持好，靠的是宣传、组织和处理好与成员的关系，而不是靠个人独断。
- **问题摆上桌面**：有分歧就开会讨论、当面对齐，不要在背后议论；议而不决往往源于不肯把问题摊开。
- **互通情报**：成员之间互相通报各自掌握的情况，才能取得"共同的语言"，否则各说各话、形不成决议。
- **不耻下问**：不懂的先问下级、先当学生再当先生，不装懂；综合了下级的正确意见，决定才站得住。
- **弹钢琴（多任务统筹）**：十个指头都要动，但不能同时按下；围绕一个中心工作，同时有主有次地兼顾其他方面，避免只顾一点丢掉其余。
- **抓紧**：抓住要害工作就要抓得很紧、不松手——"抓而不紧，等于不抓"，样子像抓其实抓不住。
- **胸中有数**：对关键问题要有基本的数量分析（统计、百分比、决定质量的数量界限），不可凭印象拍脑袋。
- **安民告示**：开会前把议题、要解决什么问题、需备材料提前告知，让人早作准备；没准备好就不要急于开会。
- **集体讨论与请示报告**：重大事项集体讨论决定，反对个人包办；同时保持事前请示、事后报告的信息通道。
- **简明扼要**：讲话、文件、会议都力求简短，不拖沓。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《党委会的工作方法》十二条
- **问题**: 各领导机关"担负很繁重的任务"，方针政策虽对，但"如果在工作方法上疏忽了，还是要发生问题"；有些集体开会抓不住重点、议而不决。
- **方法论的使用**: 作者把集体领导的经验归纳为可照做的十二条：当好"班长"、问题摆到桌面上、互通情报、不耻下问、弹钢琴、抓紧、胸中有数、安民告示、精兵简政、团结意见不同的同志、力戒骄傲、划清界限。
- **结论**: 有了这些方法，才能把集体的领导工作搞好；"我们一定要讲究工作方法"。
- **结果**: 形成了一份可直接对照执行的团队/委员会工作操作清单。（第四卷《党委会的工作方法》）

### 案例 2: 建立报告制度、健全集体领导
- **问题**: 有些领导机关不请示不报告，"以致中央不明了或者不充分明了他们重要的活动和政策的内容"，因而发生本可避免的损失；另有些机关"个人包办和个人解决重要问题的习气甚为浓厚……党委委员等于虚设"。
- **方法论的使用**: 作者一方面规定定期的综合性报告和请示制度（自己动手写、内容扼要、指出问题所在），一方面要求一切重要问题交集体讨论、由到会成员充分发表意见后做决定，反对个人包办。
- **结论**: 制度化的事前请示、事后报告与集体讨论，是"互通情报""问题摆上桌面"落到组织层面的办法。
- **结果**: 事前请示、事后报告者"避免了或减少了这样的损失"；集体领导制度得以健全。（第四卷《关于建立报告制度》《关于健全党委制》）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 刚接手一个跨部门委员会、项目组或管理团队，不知道该怎么主持会议、怎么把班子带起来。
2. 团队开会议而不决、会后各干各的，信息不通、口径不一。
3. 领导者事必躬亲、或个人说了算，团队没有实质讨论。
4. 手头多摊子事并行，顾此失彼，不知道该怎么兼顾。
5. 某项要害工作"抓了但没进展"，或关键决策心里没底、没有数据支撑。

### 语言信号 (用户的话里出现这些就应激活)

- "会议开不完/议而不决""一个人说了算""一言堂""事必躬亲""怎么把班子带起来"
- "多线并行怎么兼顾""抓了但没效果""怎么才算抓紧""要不要提前发议程""数字/数据在哪里"
- EN: "how to run a committee meeting / agenda in advance / align the team / keep multiple workstreams going / grasp things tightly / a loose grip is no grip at all"

### 与相邻 skill 的区分

- 与 `principal-contradiction`（抓主要矛盾与集中力量）的区别: 后者回答"该抓哪一个中心"；本 skill 回答"抓定为中心之后，怎么带团队、怎么兼顾其余、怎么抓紧不松手"。
- 与 `quantitative-grasp`（胸中有数）的区别: "胸中有数"是本清单中的**一条**；后者是把"数量分析找出质量界限"独立出来的一般方法。
- 与 `让人讲话`（三不主义、先民主后集中）的区别: 后者聚焦决策前营造敢讲真话的安全气氛；本 skill 是覆盖会议、分工、跟踪、汇报的整份领导操作清单。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **会前发议程（安民告示）**
   - 完成标准: 会议议题、要解决的问题、需提前阅读的材料在开会前发出；材料未备则不急于开会。

2. **把问题摆到桌面上、先听后断**
   - 完成标准: 有分歧的议题当面对齐（不背后议论）；主持人先充分听取成员意见（不耻下问），再作决定。
   - 判停条件: 若成员不敢讲真话 → 先营造安全气氛（参见 `让人讲话`）再回到本步。

3. **互通情报、统一口径**
   - 完成标准: 成员间就关键情况互相通报，形成共同理解；检查是否还有人信息不同步而各说各话。

4. **定中心 + 弹钢琴（多任务兼顾）**
   - 完成标准: 明确一个中心工作，同时列出围绕它必须兼顾的其他方面及各自动作；检查是否"十个指头都动"却未顾此失彼。

5. **抓紧：给要害工作定跟踪节点**
   - 完成标准: 对要害工作写明检查节点与责任人，确保"抓得很紧、毫不放松"。
   - 判停条件: 若只有布置、没有跟踪（抓而不紧）→ 补上节点，否则等于不抓。

6. **胸中有数：给关键判断配数量分析**
   - 完成标准: 对关键问题给出基本的数量分析（统计、百分比或某条数量界限），而非凭印象。

7. **集体讨论 + 事前请示、事后报告**
   - 完成标准: 重大事项经集体讨论、由成员充分发表意见后决定，不个人包办；重大进展按约定事前请示、事后报告，文字简明扼要。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一人即可独断、无需集体讨论的极小事务；或必须临机速断、来不及开会的紧急场合（原文亦承认"军队在作战时和情况需要时，首长有临机处置之权"）。
- 团队规模极小、彼此高度熟悉，套用正式会议与报告制度反而增加负担。
- 把"会前发议程、集体讨论"变成拖延的借口，迟迟不做决定。

### 作者在书中警告的失败模式

- **"一言堂"（个人包办）**：重要问题不由集体讨论而由个人决定，"党委委员等于虚设"，委员间的分歧长期不加解决，只维持形式上的一致（第四卷《关于健全党委制》）。
- **极端民主化**：把民主理解为否定集中，要求"先交下级讨论，再由上级决议"，对已成决议的执行表示种种勉强态度，结果"损伤以至完全破坏党的组织，削弱以至完全毁灭党的战斗力"（第一卷《关于纠正党内的错误思想》，ce04）。

### 作者的盲点 / 时代局限

- 部分条目（请示报告制度、集体领导的具体形态）**依赖特定组织形态**，迁移到一般团队需改写为适合自身的机制（units-merged u34 风险提示）。
- "弹钢琴"的"有节奏兼顾"缺可操作标准，实践中易沦为口号（同上）。
- "让人讲话"之后"集中"的权力由主持方掌握，缺少独立的仲裁程序（BOOK_OVERVIEW §3 立场盲点 3）。
- 该清单偏"内部领导流程"，未处理成员退出、激励衰减与动员疲劳等机制（BOOK_OVERVIEW §3 未证明假设 4）。

### 容易混淆的邻近方法论

- **抓主要矛盾与集中力量**：解决"该抓哪一个"；本 skill 解决"抓定之后怎么带团队、怎么兼顾与抓紧"。
- **胸中有数（数量分析）**：本清单的一条独立化方法，专讲数量界限。
- **让人讲话（三不主义、先民主后集中）**：决策前的心理安全，是本清单中"把问题摆到桌面上"的专门化。
