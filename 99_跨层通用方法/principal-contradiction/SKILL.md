# 抓主要矛盾与集中力量（不要四面出击）

## R — 原文 (Reading)

> "研究任何过程，如果是存在着两个以上矛盾的复杂过程的话，就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。""不能同时有许多中心工作，在一定时间内只能有一个中心工作。"
>
> — 毛泽东，《矛盾论》；《关于领导方法的若干问题》（第一卷、第三卷）

---

## I — 方法论骨架 (Interpretation)

- 面对多矛盾并存的复杂局面，不要平均用力，先找出起决定作用的那个主要矛盾。
- 主要矛盾规定或影响其他矛盾；抓住它，其余问题被带动、迎刃而解。
- 力量的使用方向要集中：主要的使用方向只应有一个，不应有两个。
- 一定时间内只设一个中心工作，不能同时有许多中心。
- 多方向都受压迫时，先在一个方向主动让步、缓和，把力量集中到另一个方向去打，避免四面树敌。
- 要反对两种毛病：不分主次的平均主义（全线出击、两个拳头打人）和树敌太多的四面出击。
- 集中的程度要够——局部上要形成压倒优势（如集中三至六倍力量先歼敌一路），否则形不成突破。
- 判定的关键是"哪个矛盾支配全局、并会随条件转移"，而不是"哪件事最急"。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 建国初期"不要四面出击"
- **问题**: 建国初多方向同时受压——既要肃清残敌、又要土改、又要稳定经济、还要处理与民族资产阶级的关系；若处处用力则"全国紧张"。
- **方法论的使用**: 分清当前主要方向，对可以争取的一方（民族资产阶级）主动让步、缓和，把力量集中向另一方向（消灭封建势力）进攻。
- **结论**: 不要四面出击，绝不可树敌太多，必须在一个方面有所让步、集中力量向另一方面进攻。
- **结果**: 收窄了打击面、缓和了紧张，争取到多数。（ce25，第五卷《不要四面出击》）

### 案例 2: 集中优势兵力，各个歼灭敌人
- **问题**: 敌强我弱、兵力有限，如何用兵最有效。
- **方法论的使用**: 不走"全线出击"的平均主义，主张每战集中绝对优势兵力（三至六倍于敌）先打一路、各个歼灭。
- **结论**: 主要的使用方向只应有一个，不应有两个。
- **结果**: 该原则被作为作战方针下达全军（第四卷《集中优势兵力，各个歼灭敌人》；原文未展开具体战例）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手上同时有多个项目/目标，资源只够做好一个或一个半，纠结该怎么分配。
2. 多个方向同时出问题、都有人催，用户倾向"全都救"却越救越乱。
3. 做年度/季度规划，列了一长串同等重要的目标，需要有人帮他砍到"只留一个中心"。
4. 竞争或对抗中被人多线施压，纠结要不要全面应战。

### 语言信号 (用户的话里出现这些就应激活)

- "事情太多做不完""资源只够做一个""该先抓哪个""哪个最重要"
- "要不要全面铺开""多线开战""每个都很重要"
- too many priorities / not enough resources / which one should I focus on
- should I go all-in on everything / we're stretched across too many fronts
- "一个都不能少""都着急"

### 与相邻 skill 的区分

- 与 `annihilation-over-attrition`（歼灭战优先）的区别: 本 skill 处理**多任务/多矛盾间的排序**，无竞争对象也适用；若用户在与对手博弈、要界定"怎么才算赢"（歼灭 vs 占地/规模），应调用 annihilation-over-attrition。
- 与 `two-points-one-focus`（两点论与重点论）的区别: 后者解决"看两面但必分主次"的认识问题；本 skill 解决"分出主次后，把力量压倒性投向一处"的动作问题。
- 与 `material-refinement`（材料加工四法）的区别: 后者是材料加工工序，与本 skill 的资源配置取向无关。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **列出全部在压的方向/矛盾**
   - 完成标准: 把当前同时拉扯你的 3 个以上方向或矛盾写成清单，每个附一句"它为何重要"。

2. **找出主要矛盾**
   - 完成标准: 指认哪一个"起领导、决定作用、规定或影响其他矛盾"，并写出一句理由。不能只写"最紧急的那个"——那是事务排序，不是主要矛盾。
   - 判停条件: 若无法判断哪个主导 → 先回到 `investigation-method` 把情况弄清（识别主要矛盾依赖充分材料）。

3. **只设一个中心，集中力量**
   - 完成标准: 明确"主要使用方向只应有一个"，把优势资源压倒性投向它；其余方向明确降为次要或暂缓。

4. **对次要方向主动让步/缓和**
   - 完成标准: 至少对一个非主要方向写出"如何暂时让步或缓和"的具体动作，避免四面树敌。

5. **复核集中程度**
   - 完成标准: 检查投向主要方向的资源是否已形成局部压倒优势（类比集中三至六倍）；否则回到步骤 3 再加码或再收缩。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 多个任务权重相当且都有硬性死线时，"只一个中心"不能一刀切，应按时序与约束排布。
- 决策者无法支配执行者全部注意力的组织环境，"只一个中心"的假设不成立。
- 仅有单一目标、无需取舍的场景。

### 作者在书中警告的失败模式

- **军事平均主义**：全线出击、两个拳头打人、把主力分割为二，企图在两个战略方向同时求胜，结果"一个拳头置于无用，一个拳头打得很疲劳"（第一卷《中国革命战争的战略问题》，ce11）。
- **四面出击、树敌太多**：多方向全面用力，结果"全国紧张"，被对手各个击破（第五卷《不要四面出击》，ce25）。

### 作者的盲点 / 时代局限

- "主要矛盾"的识别可事后追认、可证伪性弱，任何结果都容易被纳入框架（整书批判·最强反对意见 1）。
- "一定时间内只有一个中心工作"在真实多任务环境中可能过度简化（units 风险提示）。
- 以阶级/立场为唯一划分维度，把复杂关系压缩为"敌—我—友"三分，压平了中间光谱（整书批判·立场盲点 1）。

### 容易混淆的邻近方法论

- **两点论与重点论**：看两面但必分主次；本 skill 是"分出主次后如何用力量"。
- **统筹兼顾（论十大关系）**：多目标逐对权衡、都要适当安排，与本 skill 的"集中一点"取向相反，须按场景择用。
