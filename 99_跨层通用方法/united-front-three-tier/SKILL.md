# 统一战线三分法（发展进步·争取中间·孤立顽固）

## R — 原文 (Reading)

> "发展进步势力、争取中间势力、反对顽固势力的策略……不可分离的三个环节。"
>
> — 毛泽东，第二卷《目前抗日统一战线中的策略问题》

---

## I — 方法论骨架 (Interpretation)

- 面对态度不一的多方格局（团队、行业、组织内不同群体），不用简单的"支持/反对"二分，而把各方按态度与处境分成三层，分别配置你的动作。
- 第一层——坚定支持你的"基本盘"：任务是**发展**它，让它更壮大、更稳固。
- 第二层——摇摆的"中间多数"：他们既不完全认同你、也不坚决反对你，却是决定胜负的力量；任务是**争取**他们。
- 第三层——最难沟通的少数核心反对者：任务是**孤立**（缩小其影响面），而不是与之全面开战。
- 三个环节不可分离：只顾基本盘会把自己变成小圈子（关门主义/宗派主义）；只顾拉中间而不敢对顽固者表明立场，中间者只会观望。
- 争取中间者有三个前提条件：① 自身力量足够；② 尊重对方的实际利益（不是要求其无条件付出）；③ 对强硬者作一次可见的、有分寸的坚决行动并取得成效，让中间者看到跟你合作有前途。
- 该结构也可外推——更大的格局（行业联盟、多方谈判、国际关系）同样可按对抗态势作类似分层处理。

## A1 — 书中的应用 (Past Application)

### 案例 1: 反对关门主义，团结一切可团结的力量
- **问题**: 当时党内"关门主义"要求队伍"纯粹又纯粹"，拒绝一切同盟者，把中间、动摇的力量一概推到对面，成了"孤家寡人"。
- **方法论的使用**: 作者把社会力量分三层——壮大可依靠的基本力量、争取广大的中间力量、孤立少数最顽固者，据此主张团结一切可团结的力量去对付当前主要目标。
- **结论**: 必须反对关门主义，把阵线尽可能放宽。
- **结果**: 推动形成广泛统一战线的策略路线（出处：第一卷《论反对日本帝国主义的策略》，及 ce13 所警告的反面）。

### 案例 2: 处理工商业者——按类型划分、团结多数、孤立极少数
- **问题**: 面对人数众多的工商户，若一律处置会扩大对抗面、造成混乱。
- **方法论的使用**: 分辨其差异、按守法程度分五类，把大多数划入团结/教育面，只对极少数严重违法者采取行动。
- **结论**: 把团结面放到大多数、把对抗面压到极少数，能降低混乱。
- **结果**: 按类区别对待，打击面被压到极少数（出处：第五卷《关于"三反""五反"的斗争》，及 c23）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在一个意见严重分裂的团队/部门推进改革或新方案，想知道该先拉谁、稳谁、避谁。
2. 行业里有多个玩家、立场不一，你方要推动一个联盟或行业标准。
3. 组织内有不同派别或不同声音，要推动一项决议通过。
4. 向一个群体（社区、用户群）推广新事物，面对大量摇摆的中间者。
5. 多方谈判中，需要快速判断"谁是伙伴、谁可争取、谁最难沟通"。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么团结大多数人""怎么拉拢中间派""争取大多数、孤立少数"
- "盟友 / 摇摆者 / 顽固派""别把人推到对立面"
- "EN: win the middle, build a coalition, rally the majority, isolate the few, uncommitted moderates, united front"

### 与相邻 skill 的区分

- 与 `利用矛盾、争取多数、反对少数、各个击破`(u28) 的区别: u26 对**整个局面**（含自己的基本盘）作三层配置；u28 专攻**对手/阻力阵营内部**，先分化其矛盾再收窄打击面。
- 与 `既联合又斗争`(u27) 的区别: u27 处理"已结盟伙伴之间"既合作又保持边界；u26 处理"尚未结盟的多方"如何分层争取。
- 与 `缩小打击面，区别对待`(u31) 的区别: u31 讲把出手范围控制到最小比例（数量约束）；u26 讲对三层分别配置"发展/争取/孤立"的整体动作。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **给相关各方分层**
   - 完成标准: 把各方归入三档——"坚定支持 / 摇摆可争取 / 最难沟通的少数"，每档至少列出明确的一个人或一方。

2. **对基本盘：壮大**
   - 完成标准: 给出至少一个增强基本盘的具体动作（信息同步、利益绑定、扩大参与）。

3. **对中间层：争取（三个条件自查）**
   - 完成标准: 逐条核对三个前提——(a) 自身力量是否足够；(b) 是否提出尊重对方实际利益的方案（而非要求其无条件付出）；(c) 对强硬者是否有一次可见的、有分寸的坚决行动。任一缺失，先补足再做争取。
   - 判停条件: 若中间层根本不存在（只有两极对立），退出本 skill，改走"利用矛盾/缩小打击面"等其他方法。

4. **对最顽固的少数：孤立而非全面开战**
   - 完成标准: 写出"缩小其影响面"的具体动作，并检查名单是否仍控制在极少数。
   - 判停条件: 若"最顽固"名单越列越长 → 停，回到 u31（缩小打击面，区别对待）重新划界。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- ⚠️ 把同事、合作方、异见者一律贴上"顽固派"标签加以"孤立"——这是本方法被滥用为党同伐异、制造对立面的典型风险。在平等、无强制力的组织或协作关系中，"孤立少数"缺乏可实施手段，强用会变成排挤异己。
- ⚠️ **严禁把对方妖魔化、把正常分歧"无限上纲"为敌我对抗**——本 skill 处理的是"态度分层与争取次序"，不是"给谁定敌人"。
- 纯技术问题、没有多方利益格局的场景，不必套用。

### 作者在书中警告的失败模式

- **关门主义**（"要纯粹又纯粹"）（第一卷《论反对日本帝国主义的策略》，ce13）：拒绝一切同盟者、把中间力量推到对面，"为渊驱鱼，为丛驱雀"，"只博得敌人的喝采"——正是三分法要纠正的反面。
- **宗派主义**（第三卷《整顿党的作风》，ce19）：对内排内、对外排外，只顾小团体、排斥外来力量，妨碍团结多数。

### 作者的盲点 / 时代局限

- 三分法预设一个可识别的"最顽固核心"；"孤立少数"在平等主体、无强制力的场景难以实施且可能被滥用（units-merged u26 风险提示）。
- 以阶级/立场为唯一划分依据，把复杂关系压缩为"敌—我—友"三分，对中间与独立主体的评估偏低；标签化有以定性替代论证的风险（BOOK_OVERVIEW §3 立场盲点 1）。
- 文本大量使用二元对立压缩选择空间、遮蔽光谱式的中间状态（BOOK_OVERVIEW §3 立场盲点 4）。
- 第七卷《关于划分三个世界的谈话》为**静火版非官方汇编、记录稿，可靠度较低**（BOOK_OVERVIEW §3 时代局限 4）。

### 容易混淆的邻近方法论

- 利用矛盾、争取多数、反对少数、各个击破（分化对手阵营）；既联合又斗争（与已有伙伴的关系）；缩小打击面，区别对待（数量上限）。
