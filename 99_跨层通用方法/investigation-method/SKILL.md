# 调查研究法（没有调查，没有发言权）

## R — 原文 (Reading)

> "没有调查，没有发言权。""一切结论产生于调查情况的末尾，而不是在它的先头。"
>
> — 毛泽东，《反对本本主义》（第一卷）

---

## I — 方法论骨架 (Interpretation)

- 遇到不清楚的问题，第一步不是下结论，而是先把情况弄清。
- "没有调查就没有发言权"不是态度建议，而是把调查设为发言与决策的硬性前置条件：事情没弄清，就不该拍板。
- 结论只能写在调查之后；先有结论、再去找材料印证，方向就反了。
- 调查也不是泛泛"了解情况"，而是一套可照做的作业：放下架子、眼睛向下，把一线知情者当作先生。
- 找对象要选真正有经验的人（中下级实际工作者、亲历者），而不是只听层级高或想当然的人。
- 开会要用讨论式，而不是一问一答走过场；自己主持、口问手写、亲自做记录。
- 事前备好简明的调查纲目，问题少量而要紧，围绕它展开。
- 只有拿到的一手材料才是决策依据；凭本本、传言或想象行事，多半要碰壁。

## A1 — 书中的应用 (Past Application)

### 案例 1: 湖南五县三十二天实地考察
- **问题**: 城里对农民运动一片"糟得很"，只凭二手传言无法判断农民运动究竟是好是坏。
- **方法论的使用**: 作者亲自下乡，走湘潭、湘乡、衡山、醴陵、长沙五县，从一月四日至二月五日共三十二天，在乡村和县城反复开调查会，直接听农民与农运干部的报告。
- **结论**: 所得材料与从绅士阶级那里听来的"道理"完全相反，据此得出农民运动"好得很"。
- **结果**: 主张迅速矫正一切反对农民运动的议论。（c01）

### 案例 2: 寻乌等多次调查与"我的可敬爱的先生"
- **问题**: 党内许多人粗枝大叶、不求甚解，"全然不了解下情"却在指导工作。
- **方法论的使用**: 作者以自己湖南五县、井冈山、寻乌、兴国、长冈、才溪乡等多次调查示范开调查会的做法——到会者为有经验者（寻乌一次请的是中级干部、下级干部、一个穷秀才、一个破产商会会长、一个失业小官吏），给时间、备纲目、口问手写、展开讨论、放下臭架子当小学生。
- **结论**: "开调查会是最简单易行又最忠实可靠的方法"；"没有调查就没有发言权"作者"至今不悔"。
- **结果**: 这些调查成为制定政策的依据；"下车伊始"就发议论者"十个有十个要失败"。（c11）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要为一个还不了解的目标用户群或市场拍板产品方向，却从没做过一线访谈。
2. 团队为一个方案争论不休，各方都在凭印象、二手消息或"大家都这么说"下结论。
3. 上级或他人催着出结论，手头只有本本、汇报或传言，没有一手事实。
4. 想了解一线真实状况（客户、门店、生产现场、基层执行者），却只打算发问卷或听汇报。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要直接定了""没时间调研了""情况不清楚但得拍板"
- "该怎么调研""怎么了解真实需求""怎么搞清楚真实情况"
- "我没有一手数据" / no first-hand data
- "should I just decide" / how do I find out the real situation / before I commit, do I need to research
- "大家都是这么说的""按惯例办就行""书上/领导就是这么讲的"

### 与相邻 skill 的区分

- 与 `practice-cognition-loop` 的区别: 本 skill 只管"取证"这一前置动作——要不要调查、怎么开调查会；后者管材料到手之后如何上升为理性认识、再回实践检验。
- 与 `typical-survey-verification` 的区别: 本 skill 是调查总纲，回答"要不要调、怎么调"；后者是它之下的专门化，回答"挑哪些典型（解剖麻雀）"与"如何二次核对（三不信·勾推法）"。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **判断是否具备发言权**
   - 完成标准: 能列出当前结论所依赖的一手材料来源。若一条都没有 → 进入步骤 2；若已有充分可靠的一手材料 → 跳到步骤 5。

2. **定纲目、选对象**
   - 完成标准: 写出 3–5 个要紧问题作为纲目；至少列出 1 类"一线知情者"（亲历者、实际执行者），并说明为什么选他们（眼睛向下，而不是只找层级高的人）。

3. **亲身出马，开讨论式调查会**
   - 完成标准: 由你本人主持；按纲目展开讨论（是讨论，不是一问一答走过场）；自己口问手写、做记录；拿到可复核的原始记录。
   - 判停条件: 若受访者明显不敢讲真话（等级或利害压制），改为匿名或一对一再回到本步。

4. **从材料得结论**
   - 完成标准: 每条结论都能指回具体材料；结论写在材料之后，而非预先设定结论再找材料印证。

5. **输出并标注不确定处**
   - 完成标准: 给出结论，同时明确标出哪些点仍缺材料、置信不足，作为下一步再调查的入口。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 决策可逆、代价极小、时间极紧的日常小选择——先做再改往往比先调查更划算。
- 情况已充分掌握、任务只是执行既定方案。
- 把"调查"当拖延借口：以"还没调查清楚"为由无限推迟只需动手即可获得反馈的事。
- 个人或平等主体场景需改写：原命题假设"发言权可被剥夺"，在无强制约束的关系中应改写为"先取证再表态"的自律。

### 作者在书中警告的失败模式

- **本本主义**：把书本结论、上级指示当作无需验证的真理，遇实际问题不调查便照搬照办（第一卷《反对本本主义》，ce01）。
- **浮夸风、瞎指挥风**：不调查便发号施令、报喜不报忧、虚报浮夸（第六卷《彻底纠正"五风"》，**静火版，记录稿**，ce29）。

### 作者的盲点 / 时代局限

- 可证伪性弱："先调查"几乎无法证否，也易被用作事后追认已有结论的修辞（整书批判·最强反对意见）。
- 以阶级/立场为唯一划分维度，把复杂社会关系压缩为"敌—我—友"三分，对中间与独立主体的评估偏低（整书批判·立场盲点 1）。
- "发言权"约束依赖可剥夺发言权的组织前提，迁移到平等主体场景会失真。
- 若引用第六卷内容，须注意其为**静火版记录稿**，可靠度低于官方 1–5 卷。

### 容易混淆的邻近方法论

- **实事求是（从材料引出规律）**：那是"怎样从材料得到规律"的工作路线；本 skill 是更前置的"要不要取、怎样取到材料"。
- **解剖麻雀 / 典型调查**：那是本 skill 之下的"选点与二次核对"专门化，见 `typical-survey-verification`。
