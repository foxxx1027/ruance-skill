# 实践—认识—再实践循环与两次飞跃

## R — 原文 (Reading)

> "实践、认识、再实践、再认识，这种形式，循环往复以至无穷。"
>
> — 毛泽东，《实践论》（第一卷）

---

## I — 方法论骨架 (Interpretation)

- 认识不是一次完成的，而是一个闭环：行动 → 取得经验 → 形成认识 → 再行动，一环扣一环、循环上升。
- 前半程叫第一次飞跃：从实践中得到感性材料，经思考上升为理性认识（概念、判断、规律）。
- 后半程叫第二次飞跃：把理性认识送回实践，去执行并检验它是否符合实际。
- 检验结果回到起点，修正后的认识进入下一轮——所以一次失败不是终点，而是第二阶段的反馈信号。
- 裁判是实践效果：认识对不对，要看它在实践中能否达成预期，而不是看它说得漂不漂亮。
- 这个环有两种断法：只停在经验、不上升为理论，是经验主义；只空谈理论、不落地检验，是教条主义。
- 两者对称地错，因此既要"向上"加工经验，也要"向下"把认识送回实践。

## A1 — 书中的应用 (Past Application)

### 案例 1: 战争指挥员从（特别是败仗中）学会规律
- **问题**: 没有战争经验的人开始阶段只能碰运气，不了解指导战争的规律。
- **方法论的使用**: 通过亲历大量作战——胜仗，特别是败仗——从中总结出贯穿整个战争的内部规律，懂得战略战术。
- **结论**: 有经验者能把握规律、有把握地指挥战争；换成无经验者，"又会要在吃了一些败仗之后才能理会"。
- **结果**: 说明认识须经实践多次反复（原文未展开具体战例）。（c03）

### 案例 2: 从青年学西学到找到马克思列宁主义
- **问题**: 救国该走什么路？中国人长期向西方寻找真理却屡屡失败——"为什么先生老是侵略学生呢？"
- **方法论的使用**: 作者以自己青年学"新学"，以及洪秀全、康有为、严复、孙中山等向西方找真理的一派为样本，回溯"多次奋斗都失败了"的实践检验过程。
- **结论**: 认识经实践效果被更换——直到十月革命送来马克思列宁主义，"走俄国人的路"才被证明可行。
- **结果**: 认识在实践检验中被置换，进入新的循环。（c21）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一次尝试失败了，用户问"是不是说明这方向根本错了、该放弃还是该修正再来"。
2. 做过不少事、积累了一堆经验，但停留在零散感受，想提炼成可复用的规律。
3. 计划或方案想了很久，迟迟不动手，或反过来一直在做却从不回头总结。
4. 想为某个判断设定"检验—修正"的机制，想知道一轮之后该看什么、怎么迭代。

### 语言信号 (用户的话里出现这些就应激活)

- "失败了是不是方向错了""还要不要再试一轮""怎么验证这个想法"
- "经验怎么总结成规律""做了很多但说不出所以然"
- "光想不做" / "光做不想" / 想而不做，做而不想
- did the failure mean I was wrong / should I iterate again / how do I validate this idea
- all talk no action / all action no thinking / turn experience into a principle

### 与相邻 skill 的区分

- 与 `material-refinement` 的区别: 那四法（去粗取精等）是第一次飞跃内部的加工工序；本 skill 是覆盖两次飞跃与反复循环的整体框架。
- 与 `investigation-method` 的区别: 后者专管"取到一手材料"这一前置动作；本 skill 管材料到手后"上升为认识、再回实践检验"的全过程。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **取一手经验**
   - 完成标准: 列出至少一条你亲自经历或亲自操作得到的、带结果的证据（而非仅转述他人或纯推演）。

2. **第一次飞跃——上升为认识**
   - 完成标准: 形成一句可检验的判断或假设（形如"我以为 X 会导致 Y"）。
   - 判停条件: 若仍只在罗列现象、没有形成判断 → 先跳到 `material-refinement` 做加工，再回到本步。

3. **第二次飞跃——送回实践检验**
   - 完成标准: 设计一个能观测结果的行动或小实验并执行；事先写清可观测的指标是什么。

4. **依反馈修正，进入下一轮**
   - 完成标准: 记录哪些判断被证实、哪些被推翻，并写出下一轮要改什么。
   - 判停条件: 若反馈不明确或证据不足 → 回到步骤 1 再做一轮，不要强行下终局结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 长周期、多变量、反馈严重滞后的场景里，"实践检验"的归因非常困难，不能简单用一次结果给认识定罪。
- 一次性、可逆的琐碎事务，走完整循环反而浪费时间。
- 纯理论/逻辑推演类问题（无需也无从用实践效果检验）。

### 作者在书中警告的失败模式

- **经验主义**：把局部经验误认为普遍真理，只信自己经验、不上升到理论，遇到新情况仍按旧办法（第三卷《整顿党的作风》，ce18）。
- **教条主义**：只掌握理论词句、不落地检验，把理论当"现成的灵丹圣药"（第三卷《整顿党的作风》，ce17）。两者恰是同一个环的两种断法。

### 作者的盲点 / 时代局限

- 循环概念本身难以证伪，"反复多次才能正确"几乎无法证否（units 风险提示）。
- "实践检验"在长周期、多变量场景中反馈滞后、归因困难，存在以结果倒推动机的风险。
- 文本把"科学性"与"党性"合并处理，对非本立场视角缺乏内在同情，使自我确证强、自我证伪弱（整书批判·立场盲点 2）。

### 容易混淆的邻近方法论

- **感性材料加工四法（`material-refinement`）**：第一次飞跃内部的四道工序。
- **调查研究总纲（`investigation-method`）**：为循环提供原材料的前置动作。
