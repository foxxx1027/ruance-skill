# 典型调查与二次检验（解剖麻雀·三不信）

## R — 原文 (Reading)

> "麻雀虽然很多，不需要分析每个麻雀，解剖一两个就够了。""调查有两种方法，一种是走马看花，一种是下马看花。""不做正确的调查同样没有发言权。"
>
> — 毛泽东，《我们党的一些历史经验》（第五卷）；《反对本本主义》（第一卷）

---

## I — 方法论骨架 (Interpretation)

- 要了解一大片对象，不必逐个普查；有代表性地深入解剖一两个典型，就能"从个别看出普遍性、以点带面"。
- 典型要少——"解剖一两个就够了"，不必每个都分析；但必须亲自动手，深入下去。
- 调查分两种方式配合用：走马看花是面上的快速概览，下马看花是点上的深入蹲点；关键对象必须下马看花。
- 选点不是随手挑，而要覆盖面——例如按最坏、中等、最好各取一个，避免只看到顺利面。
- 调查所得不能当终局真相："不做正确的调查同样没有发言权"，调查本身也要被检验。
- 二次检验的核心是三不信：第一，别人不一定讲真话；第二，自己对了解来的情况不一定理解得好；所以一次调查未必真正认识。
- 核对的具体办法是勾推法——先查当事人周围的环境与相关人（先访原告被告周围的人），再回头看当事人本身，兼听比较。
- 经检验后仍存疑的，就当作待验证的假设继续查，而不是当作结论使用。

## A1 — 书中的应用 (Past Application)

### 案例 1: 解剖麻雀与"走马看花、下马看花"
- **问题**: 领导者（含外国党领导人）不了解农村，发出的指示不符合实际；本党同志也常只作浮泛了解。
- **方法论的使用**: 主张主要领导亲自动手了解一两个农村，"解剖一两个麻雀"；调查分走马看花（概览）与下马看花（深入）两种，须用后一种分析一朵"花"；并强调要同时调查两方——"只了解工人，不了解资本家，我们就没有法子同资本家开谈判"。
- **结论**: 提出典型调查（解剖麻雀）＋两种看花方式并用的调研范式。
- **结果**: 成为其调查方法的标志性表述。（c24）

### 案例 2: 三十个生产队选三个
- **问题**: 大跃进之后，中央和省一级都不摸底，"情况不明、决心不大、方法不对"。
- **方法论的使用**: 作者先检讨自己"官做大了……调查做得很少了"，随后示范选点——一个公社三十个生产队，按一个最坏的、一个中等的、一个最好的各调查一个；并提出"情况明，决心大，方法对"三步。
- **结论**: 选取最坏/中等/最好三类典型，而非只看顺利面。
- **结果**: 号召大兴调查研究，把实事求是的精神恢复起来。（c25，**第六卷·静火版，记录稿**）

### 案例 3: 与斯诺谈"三不信"
- **问题**: 一次调查未必可靠，如何对待调查所得。
- **方法论的使用**: 作者据几十年调查经验提出——"第一，别人不一定讲真话。第二，自己对于了解来的情况不一定能够理解得好"；并现场教斯诺用一个月调查两个工厂、两个农场、两所学校，逐个阶层看生活、看情绪。
- **结论**: "调查一次也不一定能够真正认识"，须反复调查、与对象交朋友。
- **结果**: 体现"没有调查（正确的调查）就没有发言权"背后的自我设限。（c31，**第七卷·静火版，记录稿**）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对一个庞大对象（数千家门店、大量客户、成堆反馈），纠结要全量普查还是挑几个看看。
2. 手头只有少量访谈或数据，想据此推断整体，但不确定样本够不够、有没有代表性。
3. 拿到一份调研结论或二手信息，怀疑来源说了假话、或自己理解有偏差，想知道怎么核对。
4. 给领导/客户一份"典型摸排"方案，需要决定挑哪几个点、用深入还是概览的方式。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要普查""抽几个看看""挑个典型的""这个样本有代表性吗"
- "这个数据/结论可信吗""一次调查够不够""他说的能信吗"
- do I need to survey everyone / pick a representative case / is one interview enough
- can I trust this info / how do I verify this claim / this sample seems biased
- "大家都这么说""只看了一家""数据是对方给的"

### 与相邻 skill 的区分

- 与 `investigation-method` 的区别: 那是调查总纲（要不要调、怎么开讨论式调查会）；本 skill 是它之下的专门化，只解决"挑哪些典型"与"如何二次核对"。
- 与 `material-refinement` 的区别: 本 skill 管"取到可信材料"；后者管材料到手后如何加工上升为判断。
- 与 `practice-cognition-loop` 的区别: 那是"实践—认识—再实践"的完整循环；本 skill 只覆盖其中"取材料＋复核材料"一段。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **决定是否典型化，并按面选点**
   - 完成标准: 按"最坏/中等/最好"（或按关键分层）各选 1–2 个对象，写出选点理由；点数控制在"一两个就够了"，不求全。
   - 判停条件: 若对象高度异质、单个典型无法代表整体 → 增加分层或改用规范抽样，不要用一个典型硬推整体。

2. **分方式取材料（走马看花 / 下马看花）**
   - 完成标准: 对每个对象明确用哪种方式——面上用"走马看花"快速概览，点上用"下马看花"亲自深入蹲点；关键对象必须亲自出马下马看花。

3. **对调查本身做二次检验（三不信）**
   - 完成标准: 逐条自问两件事——受访者是否可能没讲真话？我是否可能理解错？对存疑处用"勾推法"，先查当事人周围的环境与相关人，再回头核对当事人本身。

4. **定结论并标注置信**
   - 完成标准: 输出结论，并标明由哪个典型、哪条旁证支撑，哪些仍是待验证假设。
   - 判停条件: 若旁证与主证据冲突 → 回到步骤 1 重选典型，或回到步骤 3 补查旁证。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要总体精确统计或比例的场合，应做普查或规范抽样；解剖一两个典型会系统性失真。
- 对象高度异质时，"典型要少（一两个）"的前提不成立。
- 低风险、一次即可核实的事实，无需对调查本身反复做二次检验，否则只是拖延。

### 作者在书中警告的失败模式

- **轻信一次调查**：把一次调查所得当作终局真相，忽视受访者可能不说真话、自己可能理解有误，缺少勾推法与环境核对（第七卷《与斯诺的谈话》《恢复联合国席位后的谈话》，**静火版，记录稿**，ce34）。
- **主观性、片面性、表面性**：只了解一方、只看见树木不看见森林——典型调查尤其容易选到偏向样本（第一卷《矛盾论》，ce07）。

### 作者的盲点 / 时代局限

- 典型的"代表性"依赖先验判断，选错样本就会由个别误推一般。
- "二次检验"如何操作化（查何种旁证、几次为准）原文未给标准。
- 若引用第六、七卷材料，须注意其为**静火版记录稿**，可靠度较低（第七卷最低），不宜作为方法论的可靠来源。

### 容易混淆的邻近方法论

- **调查研究总纲（`investigation-method`）**：那是"要不要调、怎么调"；本 skill 是其下"选点＋复核"的专门化。
- **感性材料加工四法（`material-refinement`）**：材料到手后的加工工序，与本 skill 的"取证与核对"衔接。
