# 两点论与重点论（一分为二·两条战线斗争）

## R — 原文 (Reading)

> "所谓片面性，就是不知道全面地看问题。……只了解原告一方、不了解被告一方……一句话，不了解矛盾各方的特点。"
>
> — 毛泽东，第一卷《矛盾论》

---

## I — 方法论骨架 (Interpretation)

- 看任何一个对象，都要同时看到它的两个侧面：成对的性质、正反两方、利弊、高潮与低潮。只抓一面就下结论，叫片面性。
- 但看到两面之后不能就此打住，更不能把两面等量齐观、各让一步了事。必须分出哪一面是主要的、哪一面是次要的，哪一面是主流、哪一面是支流。
- 把两面平列、不分主次，并不等于"全面"，而是折衷主义——这正是本方法明确反对的。
- 对已经发生的事（尤其是错误与挫折）取分析态度：既指出错误的一面，也承认其中一致或有价值的一面，不搞全盘否定，也不搞全盘肯定。
- 纠正一种偏向时，要同时防止相反的另一种偏向：反"左"时也防右，反右时也防"左"（两条战线斗争），使纠偏不至于从一个极端荡到另一个极端。
- 处理分歧时求大同、存小异：大方向一致即可合作，不因枝节差异否定大同。
- 一句话：全面（看两面）＋有主次（分重点）＋对称纠偏（反一偏同时反另一偏），三者合起来才成立。

## A1 — 书中的应用 (Past Application)

### 案例 1: 对四中全会至遵义会议时期的"两方面分析"
- **问题**: 评价党史上一段犯错误的领导时期，很容易走向绝对否定。
- **方法论的使用**: 作者亲自示范"对任何问题应取分析态度，不要否定一切"——一方面指出该时期中央的政治、军事策略和干部政策在主要方面都是错误的；另一方面指出当时犯错误的同志在反对蒋介石、主张土地革命和红军斗争这些基本问题上与自己没有争论。
- **结论**: 应养成分析习惯，反对绝对肯定或绝对否定，并引列宁"具体分析具体情况"为依据。
- **结果**: 为后来"惩前毖后、治病救人"式地处理历史问题定下基调（出处：第三卷《学习和时局》，及 c17）。

### 案例 2: 1956 年罢工罢课与匈牙利事件的"二重性"
- **问题**: 社会主义社会里出现群众闹事与国际风波，如何定性处置。
- **方法论的使用**: 作者不作单向压制，而是逐层分析闹事原因（物质要求、官僚主义、缺乏教育），主张用"团结—批评—团结"处理；并举匈牙利事件说明坏事在正确处置下可以转化为好事。
- **结论**: 对"乱子"要作两面看，坏事可以变好事。
- **结果**: 提出"坏事变好事"的判断方法（出处：第五卷《关于正确处理人民内部矛盾的问题》，及 c22）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要评价一个"有功也有过"的人（同事、下属、合作方、历史人物），纠结该不该全盘否定或全盘肯定。
2. 面对一件"有利有弊"的决策、政策或方案，想判断该不该上、如何取舍。
3. 处在两种相反意见之间（团队里有人过"左"、有人过右），想同时纠偏而不倒向任何一边。
4. 因为一个枝节性小分歧，就要否定整段合作或整体关系。
5. 遇到挫折或坏消息，只看到坏的一面，陷入全盘否定。

### 语言信号 (用户的话里出现这些就应激活)

- "他是好人还是坏人""到底该全面肯定还是全盘否定"
- "这事有利有弊，到底怎么算""两边都有道理，我该听谁的"
- "既怕…又怕…""不能一棍子打死""既要…又要…"
- "EN: both sides, pros and cons, weigh the two, is it good or bad, should I reject it entirely, avoid either-or"

### 与相邻 skill 的区分

- 与 `抓主要矛盾与集中力量`(u11) 的区别: u11 是在**多个矛盾之间**挑一个中心、集中力量（选择与聚焦）；本 skill 是就**同一个对象**同时兼顾两面后再分主次（认识与评价）。
- 与 `分析—综合四步法`(u15) 的区别: u15 是处理问题的**流程**（提出问题→分析→综合→给办法）；本 skill 是分析时的**态度准则**（全面且有主次）。
- 与 `具体问题具体分析` 的区别: 后者强调对象的特殊性、反对公式硬套；本 skill 强调对同一对象的两面性与主次之分。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出对象的两面**
   - 完成标准: 写出至少两条对立的具体表现（正/反、利/弊、功/过），每条有可指认的事实依据。
   - 判停条件: 若只能找到一面（缺少基本事实），先回到"调查研究"补材料，或确认这是单纯事实查询后退出本 skill。

2. **判定主次，给出依据**
   - 完成标准: 明确写出"主流是 X、支流是 Y"，并说明判断依据（影响范围、持续时间、是否决定性质）。
   - 判停条件: 若两面确实势均力敌、无法分出主次，如实说明"需更多信息"，不要强行平列或各打五十大板（那会滑向折衷主义）。

3. **给出结论，并检查对称纠偏**
   - 完成标准: 结论既非全盘肯定也非全盘否定，且指明了主次；若涉及纠偏，须同时指出要防止的相反偏向；若涉及分歧，须标出可保留的"小异"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯信息 / 事实查询（"某件事发生在哪一年"）——无需两面权衡。
- 需要即刻决断、无暇兼顾两面的紧急单一动作。
- 简单的二选一，且两面**并非同一对象的两面**（那是取舍问题，走"抓主要矛盾"或决策类 skill）。
- 评价缺乏基本事实、只有立场和情绪时——先补事实，否则"两面"会沦为各说各话。

### 作者在书中警告的失败模式

- **主观性、片面性、表面性**（第一卷《矛盾论》，ce07）：只看一面、只看局部或表面就下结论，"这样的人就往往碰钉子"。
- **亡国论与速胜论**（第二卷《论持久战》，ce14、ce15）：抓住单一因素（敌强我弱）无限夸大，或拿一时一地的局部现象代替全体，都是"片面性＋主观性"——只看一面的必然下场。
- **军事平均主义**（第一卷《中国革命战争的战略问题》，ce11）：把有限力量"平列"投向多个方向、不分主次——对应本方法中"两面平列"的折衷主义错误一端。

### 作者的盲点 / 时代局限

- 文本大量使用二元对立（进步/倒退、团结/分裂）压缩选择空间，遮蔽光谱式的中间状态（BOOK_OVERVIEW §3 立场盲点 4）。本 skill 的"两面"容易被简化为"非黑即白"，使用时须警惕把连续谱压成两极。
- "主次 / 主流"的判定常依赖判断者立场（units-merged u14 风险提示）：同一事实，立场不同可以指定不同的"主流"，易被用来为既定偏向两边找理由——故须要求给出可核查的依据。
- "两条战线斗争"在权力不对等时可能变成打击异见的工具；且其纠错以不否定既有总纲为前提，反思边界受政治框架限制（BOOK_OVERVIEW §3 时代局限 3）。

### 容易混淆的邻近方法论

- 抓主要矛盾与集中力量（多矛盾中择一聚焦）；分析—综合四步法（问题处理流程）；统筹兼顾（论十大关系，多对关系逐对权衡）；具体问题具体分析（矛盾特殊性）。
