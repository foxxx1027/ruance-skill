# 惩前毖后，治病救人（团结—批评—团结·一看二帮）

## R — 原文 (Reading)

> "从团结的愿望出发，经过批评或者斗争，分清是非，在新的基础上达到新的团结。"
>
> — 毛泽东，第五卷《关于正确处理人民内部矛盾的问题》；并见第三卷《整顿党的作风》"惩前毖后，治病救人"

---

## I — 方法论骨架 (Interpretation)

这套方法回答的是"人犯了错，究竟该怎么办"。它的落点不是惩罚，而是把事弄清楚、把人拉回来、让关系比原来更结实。

- **起点先定方向**：处理的目的从一开始就明确为"改进问题、帮助这个人"，而不是"证明他坏"或出口气。没有这个起点，后面的批评就会变质成整人。
- **是非必须讲清**：错误要揭发、要说明白（惩前毖后），不回避、不留情面，否则同样的问题会反复。
- **批评对着"事"**：指出问题、分析原因，但指向的是行为和错误，不否定整个人的价值。
- **帮是必需环节**：一看二帮、一曰斗二曰帮——批评之后要给出路、给方法、给支持，光斗不帮不算完成。
- **终点是新的团结**：批评过后关系要重新稳定，而不是把人打入另册、让人人自危。
- **校验靠实效**：一个人是否真心改好，不看他的表态，而看他的行为在团队里产生的实际效果。

通用表述：对事不对人、目的是改进而非羞辱、边纠错边帮扶、以实践效果（而非态度）检验是否真正改好。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1956 年罢工罢课事件与匈牙利事件
- **问题**：社会主义社会里出现群众闹事和国际风波，如何定性、如何处置。
- **方法论的使用**：作者没有简单压制，而是逐层分析闹事原因（物质要求、官僚主义、缺乏教育），主张用"团结—批评—团结"的方法来解决，并把闹事看作"改善工作、教育干部和群众的一种特殊手段"。
- **结论**：对"乱子"要作两面看，坏事在一定条件下可以转变成好事。
- **结果**：由此形成对群众闹事既不迁就、又不放弃批评教育的处置办法。
- **来源**：第五卷《关于正确处理人民内部矛盾的问题》

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队里有人犯了错、造成损失，用户在纠结"要不要批评、怎么批评、批到什么程度"。
2. 团队内部出现分裂、互相攻击或"人人自危"的气氛，用户想既止住问题又保住队伍。
3. 用户要对同事/下属做一次绩效面谈或追责，担心处理完把人推走或搞僵关系。
4. 用户面对一位有过过失但仍是骨干的成员，纠结"该不该继续留用、如何让他改"。
5. 用户在"不追究怕纵容"与"追究怕伤和气"之间摇摆，需要一套既讲是非又留关系的流程。

### 语言信号 (用户的话里出现这些就应激活)

- "同事/下属犯了错，我该怎么处理"（how should I handle a colleague's mistake）
- "要不要批评他／会不会显得太狠"（should I criticize them / am I being too harsh）
- "怕处理完人心散了"（afraid of demoralizing the team）
- "怎么做到对事不对人"（how to criticize the behavior not the person）
- "团队内部吵架/分裂了怎么办"（internal conflict / team is polarizing）

### 与相邻 skill 的区分（初稿）

- 与 `cooperate-and-struggle`（既联合又斗争，u27）的区别：那处理的是"同盟者/外部关系"，本 skill 处理"内部自己人犯错"。
- 与 `narrow-the-target`（缩小打击面，u31）的区别：那讲把处理范围压到最小，本 skill 讲对当事人本人如何"斗"与"帮"。
- 与 `two-points-one-focus`（两点论与重点论，u14）的区别：那是分析姿态（既看两面又分主次），本 skill 是处置错误的具体流程。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定矛盾性质**
   - 完成标准: 能明确写出"责任人是我想留在关系里的人"，并确认这是可教育、可转化的内部问题。
   - 判停条件: 若属触犯法律的严重违规，或对方是外部对手/不可调和的敌对关系 → 不走本流程，改用正式程序或对抗策略（见 B 段）。

2. **定起点、摆事实**
   - 把目的明确为"改进问题 + 保住关系"（团结的愿望）；把错误的经过、影响、责任讲清楚、不回避。
   - 完成标准: 写下一句"要解决的具体问题 + 当事人 + 对事不对人的事实描述"。

3. **分清是非、给出批评**
   - 就错误本身展开批评或讨论，区分主要责任与客观因素，不把错误上升为对人格的否定。
   - 完成标准: 能列出"哪些是错误、错在哪、原因是什么"，且措辞指向行为而非人品。

4. **一看二帮**
   - 批评之后必须给出改进路径与帮助（资源、方法、期限）。
   - 完成标准: 当事人拿到可执行的改进方案和所需支持。
   - 判停条件: 若当事人拒绝一切改进且持续损害团队 → 转为明确边界与问责，不再适用"治病救人"式的耐心。

5. **达到新团结并校验**
   - 事后关系恢复常态、不搞另册；以行为在团队中的实际效果（而非表态）判断是否真改。
   - 完成标准: 经过一个时间窗口的行为观察，确认错误不再重复且协作恢复。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **对方是外部对手或不可调和的敌对关系**：本方法的前提是"内部人、想留住关系"，对敌我关系强行使用只会自我麻痹。
- **触犯法律、涉嫌违法违纪的严重行为**：应走正式调查与法律程序，不能用"批评—团结"代替规程与问责。
- **借"批评"之名行打压、排挤之实**：若目的是羞辱、立威或排除异己，这套流程会被滥用成话术。
- **一味和稀泥、不辨是非**："团结的愿望"不等于不追究；为维持和气而回避讲清错误，直接违背"惩前毖后"。

### 作者在书中警告的失败模式

- ce21 装腔作势、借以吓人，对同志大讲"残酷斗争、无情打击"——对敌人毫无用处，对同志只有损害。
- ce27 对人民内部用命令主义态度和强制手段，混淆两类不同性质的矛盾，可能使非对抗性矛盾发生对抗。
- ce32 "怀疑一切、打倒一切"，不作具体分析地扩大打击面，最终"一定要走向反面"。

### 作者的盲点 / 时代局限

- 起点"团结的愿望"由掌权一方界定，对"团结不了"的少数会被转入敌我范畴；边界由执政一方掌握，缺少独立的仲裁程序（BOOK_OVERVIEW 第 3 节·立场盲点 3）。
- 以群众运动替代常规法治程序，削弱了纠错渠道的中立性与可预期性（同上）。
- "看效果判断动机"存在以结果倒推动机的循环：结果好即认定动机好，难以独立检验（units-merged u35 风险提示）。

### 容易混淆的邻近方法论

- `cooperate-and-struggle`（既联合又斗争，u27）：对象是同盟者/外部关系，非内部错误。
- `narrow-the-target`（缩小打击面，u31）：讲处理范围的最小化，非对个人的斗与帮。
- `two-points-one-focus`（两点论与重点论，u14）：是评价方法，非处置流程。
- `let-people-speak`（让人讲话，u51）：是决策前的意见征集，非纠错后的处理程序。
