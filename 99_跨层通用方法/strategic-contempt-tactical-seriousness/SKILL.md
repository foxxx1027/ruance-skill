# 战略上藐视敌人，战术上重视敌人（纸老虎双层判断）

## R — 原文 (Reading)

> "在战略上我们要藐视一切敌人，在战术上我们要重视一切敌人。"
>
> — 毛泽东，第五卷《一切反动派都是纸老虎》

---

## I — 方法论骨架 (Interpretation)

- 对一个似乎强大得多的对手，做**两个不同层次**的判断，而且必须成对使用。
- 第一层（战略 / 本质）：从本质和长远看，貌似强大者往往笨重、虚弱、终将被取代——是"纸老虎"。据此确立信心、敢于入局、敢于斗争。
- 第二层（战术 / 具体）：在一场场具体交锋中，必须把它当"真老虎"——认真准备、谨慎应对、集中全力、不打无准备之仗。
- 两层的对象不同：第一层看的是**整体与长远**，第二层看的是**每一次具体行动**。正因对象不同，结论相反也不算矛盾。
- 诀窍在于**不把两层混淆**：用战略层的信心去处理战术层的具体问题 → 轻敌；用战术层的谨慎去否定战略层的信心 → 丧失斗志。
- 缺任一半都会失败：只有"藐视"会变成冒险轻敌；只有"重视"会变成畏敌不前。两面合起来，才是"敢于斗争、善于斗争"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 恢复联合国席位——多谋善断与"为将当有怯弱时"
- **问题**: 中国刚恢复联合国席位，"毫无准备怎么办"，又须防止被胜利冲昏头脑。
- **方法论的使用**: 作者一面自省"我对美国的那根指挥棒，还有那么多的迷信"（坦言其护士长对联合国表决的预判比他还准），一面引曹操告诫夏侯渊"为将当有怯弱时"、恃勇致败的史例提醒代表团；并重申"不打无准备之仗"，主张边准备边去。
- **结论**: 决策要"多谋而善断、看准了就下决心"，同时保持谨慎、不轻敌。
- **结果**: 形成"敢于去、又要认真准备"的姿态（出处：第七卷《恢复联合国席位后的谈话》，**静火版，记录稿**，可靠度较低，及 c32）。

### 案例 2: 平型关、台儿庄之后反对"冲昏头脑"
- **问题**: 局部胜仗后出现轻敌、主张"准决战"、把胜利寄托于外援的急性病。
- **方法论的使用**: 作者逐一列举这些表现并统称为"政治上军事上的近视眼"，以持久战的总判断加以校准——不被一时胜利冲昏，仍须按具体条件谨慎处置。
- **结论**: 小胜不能代替全局判断；战术上仍须重视困难。
- **结果**: 徐州战役并未成为"准决战"（出处：第二卷《论持久战》，及 c07）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对一个体量、资源远强于自己的对手（大厂、头部公司），纠结"要不要入局 / 敢不敢竞争"。
2. 已经决定要打，但在"必须建立信心"与"不能轻敌、要认真准备"之间找不到平衡。
3. 刚赢了一场，团队开始膨胀、觉得对手不过如此，需要有人校准。
4. 反过来，被对手的声势吓住，过于畏敌、不敢行动，需要重新认识对手的本质。
5. 需要同时向团队传递"战略上有信心"和"战术上要认真"两个信号。

### 语言信号 (用户的话里出现这些就应激活)

- "对手太强了，要不要上""他真有那么可怕吗""我们是不是必输"
- "既要自信又不能轻敌""赢了之后有点飘"
- "EN: paper tiger, strategic contempt tactical seriousness, confidence vs rigor, David vs Goliath mindset, don't be overawed"

### 与相邻 skill 的区分

- 与 `两手准备`(u25) 的区别: u25 讲"向最坏可能作准备"（风险管理动作）；本 skill 讲对同一对手作**本质与具体两个层次**的判断（心态与判断框架）。
- 与 `持久战：节奏控制`(u22) 的区别: u22 判"这场对抗是长期还是短期"并分阶段；本 skill 判"同一对抗在两层各取什么态度"。
- 与 `四对矛盾分析法`(u23) 的区别: u23 用多个维度评估双方力量；本 skill 专门处理"本质—现象"这一对，且强调两面不可分离。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **分离两个层次，分别判断**
   - 完成标准: 明确写出战略 / 本质层的判断（对手的长期弱点、终局趋势，据此确立信心）与战术 / 具体层的判断（本次交锋对手的实力量、我须认真准备之处），二者分开书写。
   - 判停条件: 若任务中不存在明确对手（纯技术 / 平等合作），退出本 skill。

2. **检查两面是否成对**
   - 完成标准: 确认结论同时包含"敢于行动的信心"与"具体准备的动作"，缺任一项则补齐。**只有"纸老虎"这半句 = 冒险轻敌，必须改写；只有"真老虎"这半句 = 畏敌不前，也必须改写。**

3. **落到一次具体行动上**
   - 完成标准: 给出下一步具体动作（怎样认真准备、怎样集中全力），并说明它与"战略信心"如何互不冲突。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯技术性、无对抗对象的任务（如学一门技能、做一个内部工具），硬套"敌人"框架会制造不必要的对抗感。
- 需要就事论事的平等合作、长期伙伴关系——把对方设为"敌人"会损害关系。
- 目标只是日常风险处置、无需建立长期信心时，用"两手准备"更贴切。

### 作者在书中警告的失败模式

- ⚠️ **最常见的误读：只取"纸老虎"那半句，删掉"战术上重视"——这直接变成冒险轻敌**。对应的失败模式是**速胜论**（第二卷《论持久战》，ce15）：夸大己方长处、轻视困难、不承认强弱现实，"一叶障目，不见泰山"，"勉强行去，败军亡国，结果和失败主义者没有两样"。
- 另一端是**革命急性病与悲观思想**（第一卷《星星之火，可以燎原》，ce02）：或过度乐观（急性病→盲动），或过度悲观（丧失信心→放弃艰苦工作）。两层判断失衡，即落入这两种极端之一。

### 作者的盲点 / 时代局限

- **"本质虚弱、终将失败"是信念性的终局判断，不可证伪**（units-merged u24 风险提示）；把它当作既定事实，会失去对对手真实威胁的评估能力。
- **"纸老虎"叙事用于竞争场景可能助长轻敌或对抗升级**（同上）——本 skill 的成败全看是否坚持"两面成对"。
- 文本大量使用二元对立（进步/倒退、团结/分裂）压缩选择空间（BOOK_OVERVIEW §3 立场盲点 4）；"敌人"框架易把复杂的竞争关系简化为敌我对抗。
- 相关第六卷文本为**静火版非官方汇编**，含记录稿 / 节选，可靠度较低（BOOK_OVERVIEW §3 时代局限 4）。

### 容易混淆的邻近方法论

- 两手准备（向最坏可能准备）；持久战：节奏控制（长期 / 短期的阶段划分）；四对矛盾分析法（多维度评估力量）；执行有利决战，避免不利决战（要不要打这一仗）。
