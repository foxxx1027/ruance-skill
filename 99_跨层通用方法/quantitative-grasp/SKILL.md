# 胸中有"数"（数量分析找出质量界限）

## R — 原文 (Reading)

> "胸中有'数'。……对情况和问题一定要注意到它们的数量方面，要有基本的数量的分析。"
>
> — 毛泽东，第四卷《党委会的工作方法》

---

## I — 方法论骨架 (Interpretation)

- 处理任何涉及全局的问题之前，先弄清它的"数量方面"：有多少人、多少资源、各自占什么比例、如何分布。
- 不要求精确到小数，而要有"基本的数量分析"——量级、结构、百分比。没有这个底，政策就成了"无根据地、主观地决定问题"。
- 更关键的是找出**决定质量的数量界限**：越过某一条线，事情的性质就变了。例如处置面一旦超过某个比例，就把大批本可争取的人推到了对立面。
- 把数量分析直接接到政策上：用数字定政策、设上限、划档次，而不是凭印象拍脑袋。
- 有了这条红线，执行时才有可核查的约束；没有它，规则会不断被"具体情况"侵蚀。
- 一句话：先数一数（数量分析），再找那条会改变性质的线（质量界限），最后把它写进规则里。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 土地改革须先弄清各阶级的人口与土地数字
- **问题**: 领导工作中容易"无根据地、主观地决定问题"，土改的政策边界定不下来。
- **方法论的使用**: 作者以土改为例，要求在定政策之前，先弄清地主、富农、中农、贫农各占人口多少、各有多少土地这些基本数字。
- **结论**: 只有先掌握这些数字，才谈得上"据以定出正确的政策"。
- **结果**: "胸中有数"被列为党委会工作方法之一（出处：第四卷《党委会的工作方法》，及 c19）。

### 案例 2: 处置工商户按五类比例分别对待
- **问题**: 面对大量工商户，既须打击少数严重违法者，又不能扩大打击面。
- **方法论的使用**: 作者按北京五万工商户的实际比例，把它们划为守法、基本守法、半守法半违法、严重违法、完全违法五类（前二类约占百分之七十），据此分别对待；并写明不得用肉刑逼供、分批次推进。
- **结论**: 以数量分析支撑"区别对待"，把实际处置面压到少数。
- **结果**: 形成"团结多数、孤立少数"的统一战线策略，减少混乱（出处：第五卷《关于"三反""五反"的斗争》，及 c23）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要制定一项影响很多人的政策 / 规则（追责范围、补贴门槛、处罚比例），却说不清到底涉及多少人。
2. 设目标或预算时只有"多、少"的定性感觉，想要一个可核查的数字或比例。
3. 要做"区别对待"——按轻重分档处理一批对象，需要知道各档大约占多大比例。
4. 被"看着不少""感觉很多""大家都这么说"这类模糊描述困住，想判断严重程度。

### 语言信号 (用户的话里出现这些就应激活)

- "大概有多少""差不多就行""感觉挺多的"
- "要不要定个比例 / 上限""这个指标定多少合适""怎么分档"
- "EN: how many, what percentage, set a threshold, baseline data, ballpark number, proportion"

### 与相邻 skill 的区分

- 与 `调查研究法`(u01) / `调查的二次检验`(u04) 的区别: 调查是取得一手材料的完整过程（含核对真伪）；本 skill 只针对"数量方面"作结构化分析并设定界限。
- 与 `四对矛盾分析法`(u23) 的区别: u23 用多个维度刻画态势；本 skill 把其中任一维度落成可核查的数字与红线。
- 与 `精兵简政`(u49) 的区别: u49 判断"机构—任务是否匹配"；本 skill 为这类判断提供量化依据。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确要量化的关键问题与对象**
   - 完成标准: 写出 1–3 个必须回答的数字问题（人数 / 资源 / 金额 / 比例）。
   - 判停条件: 若数据不可得或明显失真，先走"调查研究"取数；取不到则如实标注不确定性并退出精确量化，退回定性判断。

2. **收集基本数量并作结构分析**
   - 完成标准: 至少给出一个总量与一个占比（分类、分布），并注明来源与统计口径；数据互相矛盾时须标注而非取一个好看的值。

3. **找出"决定质量的数量界限"并接入决策**
   - 完成标准: 明确写出一条红线（如"处置面不超过 X%"）及其越线后果，并据此给出政策 / 方案。
   - 判停条件: 若无法确定界限，先按可承受后果设一个暂时阈值并注明"待数据更新后校准"，不要跳过设界直接拍板。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 关键数据不可得、或来源严重失真时——此时量化会制造"伪精确"，比不量化更危险。
- 纯价值判断（哪种活法更好之类），本质上没有可比较的数字。
- 影响面极小的单人决定，量化成本高于收益。

### 作者在书中警告的失败模式

- **"五风"（共产风、浮夸风、命令风、特殊风、瞎指挥风）**（第六卷《彻底纠正"五风"》·静火版，记录稿；ce29）：用虚报浮夸的数字代替真实情况、脱离实际瞎指挥——这是"胸中有数"的反面：数本身就是假的。
- **忘记实事求是、只有片面思想**（第六卷《十年总结》·静火版，记录稿；ce30）：把主观愿望当成现实可能性（如"吹上八百斤、一千斤"），走了弯路。
- **浮夸谎报、欺上瞒下**（第六卷《论反对官僚主义》·静火版，ce31）：指标定得虚高，逼出一路假数据。
- **轻信一次调查**（第七卷《与斯诺的谈话》·静火版，记录稿；ce34）：数据来源未经二次检验——数字不可信，"胸中有数"就变成"胸中有假数"。

### 作者的盲点 / 时代局限

- "决定质量的数量界限"**如何确定，原文并未给出方法**（units-merged u48 风险提示）。8% / 10% 这类数字出自特定土改、五反语境，不可机械照搬，须按你的场景重新标定。
- 数据质量差时，量化指标会被滥用为"伪精确"（同上）。
- 相关 6–7 卷文本为**未经审定的记录稿 / 节选**，标点不规范、可靠度低于官方 1–5 卷（BOOK_OVERVIEW §3 时代局限 4）。

### 容易混淆的邻近方法论

- 调查研究法（取一手材料）；调查的二次检验（核对真伪）；四对矛盾分析法（多维度打量）；精兵简政（机构—任务匹配）。
