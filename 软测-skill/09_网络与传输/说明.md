# 09 网络与传输

这一层测的是报文在路上：链路可达性、ARP/DNS 解析是否被替换、TLS 与证书、会话标识与重放，以及内网里有哪些设备。典型被测物是一段网段的暴露面、一次抓不到包的连接、证书链与主机名、Cookie 的有效期。对象是「网」而不是某台机器上的配置。

## 这一层最常见的四类问题

- 抓包工具里一条请求都没有，或者只有 Wireshark 能看到流量。
- 局域网间歇断网、成片掉线又自己恢复，访问常用站点却跳到陌生页面。
- 证书与域名不匹配，或者登出之后会话还能重放。
- 内网冒出陌生设备 / IP 冲突，不知道从哪隔离、断网影响面多大。

## 这一层的 skill

| skill | 作用 | 什么时候会用到 |
| --- | --- | --- |
| network-transport-and-session | 配 TLS、校验证书与主机名，设计会话标识与超时，排查中间人、重放与登出不失效。 | 「证书和域名对不上怎么办」「登出后还能重放」 |
| network-deception-and-mitm | 在授权内网用 ARP/DNS/LLMNR 欺骗评估凭据暴露面，并分析 SNMP/TFTP/GRE 等中转。 | 「内网凭据怎么被 Responder 抓到」 |
| identity-deception-detection | 按二层、解析层、应用层判断 ARP/DNS/URL 身份替换，并给出验证与处置顺序。 | 「局域网老断网又自己好了」「证书和域名不匹配」 |
| lan-visibility-and-containment | 盘点内网设备/共享/端口，发现陌生设备后做隔离、黑白名单与 IP-MAC 绑定。 | 「内网有哪些设备、有人蹭网吗」 |
| recon-funnel-and-scoping | 摸清网段与主机暴露面，把扫描结果收敛成可验证的漏洞清单。 | 「nmap 结果太多怎么筛」「先踩点从哪开始」 |

## 跨层可复用

- api-and-interface-security（06_接口与协议）— TLS 握手之后的接口校验与对象级授权。
- middleware-fingerprint-and-triage（08_中间件与Web容器）— 端口与指纹是同一批侦察数据的两种用法。
- cloud-and-container-baseline（11_云与容器）— 安全组与云上网络暴露面。
- wireless-security-grading（10_主机与操作系统）— 无线侧的接入认证与加密，属于「最后一跳」。
- account-compromise-layering（10_主机与操作系统）— 异常登录的止损与设备分层。
- identity-deception-detection 之外的钓鱼站判断见 email-trust-boundary（10_主机与操作系统）。

## 和相邻层的分界

- 与 06 接口与协议：09 看「包能不能到、路上有没有被换、会话标识在传输层是否失效」，06 看「到了之后报文内容有没有问题」。
- 与 10 主机与操作系统：09 的对象是链路与网络设备（交换机、DNS、网关、无线），10 的对象是某一台主机的系统配置与进程。
- 与 08 中间件：09 只判「这个端口上是什么服务」，服务怎么配、有哪些配置漏洞归 08。
