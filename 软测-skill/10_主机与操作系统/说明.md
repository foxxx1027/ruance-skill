# 10 主机与操作系统

这一层测的是一台机器本身：Windows/Linux 的默认账户与默认配置、远程入口、U 盘自动运行、无线接入、账号被盗后的止损、可疑邮件、隐藏账号，以及中招后的清除顺序。典型被测物是一台刚装好的主机、一个开着的 3389、一个陌生进程与启动项。

## 这一层最常见的四类问题

- Administrator 没改名、Guest 没关、账户锁定没设，默认配置替攻击者省了事。
- 远程桌面改了端口、设了强密码，但会话无人看守，第三方远控软件被滥用。
- 插盘即中毒，自动播放关了仍然执行，找不到遗漏的入口。
- 进程陌生、端口异常外联、启动项删了又复活，或者 net user 与本地用户数量对不上。

## 这一层的 skill

| skill | 作用 | 什么时候会用到 |
| --- | --- | --- |
| host-default-surface-convergence | 把 Windows 默认账户、账户锁定、匿名访问等零散加固开关收敛成一份可核对清单。 | 「刚装好的系统安全吗」「Administrator 要不要改名」 |
| remote-access-surface-audit | 审主机与小网络的远程入口：RDP、远程注册表、远程协助与第三方远控的端口/账户/会话。 | 「3389 改了端口就够了吗」「远控软件安全吗」 |
| usb-autorun-hardening | 封堵 U 盘 autorun/自动播放入口，排查「关了自动播放仍执行」的遗漏路径。 | 「U 盘一插就中毒怎么办」 |
| wireless-security-grading | 评估并分级加固 Wi-Fi 与路由器：WEP/WPA、WPS、MAC 过滤、隐藏 SSID。 | 「改了密码还是被蹭网」 |
| account-compromise-layering | 判断账号被盗后先改密、先冻结还是先申诉，并把重要账号与日常注册账号分层。 | 「账号被顶下线了，先做什么」 |
| email-trust-boundary | 判断可疑邮件与附件能不能打开，划分重要邮箱与备用邮箱并设计口令找回。 | 「这封带 zip 的邮件能开吗」 |
| hidden-account-hunt | 用多视图交叉（net user/SAM/4624）找隐藏账号与后门账号，并做改密删除处置。 | 「net user 和本地用户数量对不上」 |
| malware-triage-order | 按隔离→定位→清除→复核的固定顺序处理木马迹象与持久化。 | 「杀不干净，重启又出现」 |
| browser-hijack-repair | 修复主页/右键菜单/快捷方式被改且反复出现的浏览器劫持。 | 「主页改不回来，改了又变」 |

## 跨层可复用

- lan-visibility-and-containment（09_网络与传输）— 主机之外的隔离、内网可见性与 IP-MAC 绑定。
- log-integrity-and-evidence（13_日志与审计数据）— 判断事件日志是否被清理、如何导出保全证据。
- cloud-and-container-baseline（11_云与容器）— 云主机与容器的基线检查。
- identity-deception-detection（09_网络与传输）— 断网与跳转先排除解析层欺骗，再谈主机。
- windows-access-control-attack（03_桌面与二进制程序）— 本地配置型提权的服务/注册表 ACL 分析。
- malware-sample-analysis（99_跨层通用方法）— 拿到具体样本后的载荷行为与配置解码。

## 和相邻层的分界

- 与 09 网络与传输：10 只看单机（账户、服务、启动项、进程、外设），09 看链路与多台设备之间的可见性。
- 与 03 桌面与二进制：10 讲「配置该不该开」，03 讲「这段二进制能不能被打」。同一台 Windows，ACL 提权分析归 03，加固清单归 10。
- 与 13 日志与审计：10 在主机上做处置，13 判日志这份数据是否可信、能否作为证据。
