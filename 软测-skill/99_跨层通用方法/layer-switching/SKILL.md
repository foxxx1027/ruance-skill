# 层次转换（战略持久/战役速决·内线中的外线）

## R — 原文 (Reading)

> "战略的持久战，战役和战斗的速决战，这是一件事的两方面。"
>
> — 毛泽东，第二卷《论持久战》

---

## I — 方法论骨架 (Interpretation)

- 当整体实力远不如对手时，不要在整体层面和它硬拼——整体上承认持久、防御、被动（"内线"），这是现实。
- 但整体被动不等于处处被动。在每一个具体的局部（一个细分市场、一场战斗、一次行动），要反过来取进攻、速决、主动（"外线"），集中优势力量快打快收。
- 关键在"层次分离"：同一场较量里，战略层与战役层取**相反的**姿态——整体求稳、局部求快；整体持久、局部速决。
- 具体机制是"把对手的一次大包围，改成我方多次小包围"：不在整体上包围对手，而是在局部上一次又一次地形成对被选目标的绝对优势。
- 每个局部的速胜都应是可控、可收的，用小胜一点一点积累，逐步改变全局的力量对比，最终翻转主动。
- 一句话：全局被动的形势下，主动不在全局争取，而在一个个局部里制造出来。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 反"围剿"——把敌之一个大围剿改为我之许多小围剿
- **问题**: 敌以大军分路"围剿"，我在整体上兵力处于劣势，无法在全局与敌决战。
- **方法论的使用**: 作者不在整体上应战，而是在每次反"围剿"中采取"诱敌深入"，集中优势兵力打敌一路，形成局部包围并速决歼灭；把敌人的一次大包围，化为我方多次小包围。
- **结论**: 以局部的速决进攻战，在整体防御中积累局部主动与战果。
- **结果**: 第一至第三次反"围剿"接连取胜，红军作战原则趋于完整（出处：第一卷《中国革命战争的战略问题》，及 c06 相关战例）。

### 案例 2: 拿破仑攻俄——战略上避免决战、以空间换时间
- **问题**: 敌强我弱、敌方求我主力决战，我方在整体上处于不利。
- **方法论的使用**: 作者以俄军放弃并焚毁莫斯科、诱敌深入后大举反攻为范例，提出"战略持久、避免不利决战、以土地换时间"——整体上不争一时胜负，把主动权留到条件对我有利的局部时机。
- **结论**: 整体上取持久与退却，不等于消极；它是为局部反攻创造条件。
- **结果**: 拿破仑军仅二万余人逃出俄国（出处：第二卷《论持久战》，及 c09）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 整体资源 / 规模远不如对手，在全局竞争中不可能速胜，但想找到保持主动的打法。
2. 在一个大市场里打不过巨头整体，考虑是否要挑细分战场单点取胜。
3. 身处长期劣势（资金少、人手少、时间被拖长），纠结该"熬"还是该"拼"。
4. 在整体被动（如被对手压制、被环境拖住）时，想找到一个能主动出手的局部切口。

### 语言信号 (用户的话里出现这些就应激活)

- "整体打不过怎么办""怎么在弱势里保持主动"
- "要不要挑一个细分市场先做""熬下去还是拼一把"
- "EN: asymmetric / David vs Goliath / play the long game, win small battles, local offense global defense, layer switching"

### 与相邻 skill 的区分

- 与 `歼灭战优先`(u20) 的区别: u20 定"局部这一仗以什么为目标"（歼灭而非击溃）；本 skill 定"整体与局部各取什么姿态"（层次分离）。
- 与 `持久战：节奏控制`(u22) 的区别: u22 把长期过程划分为阶段、分配各阶段任务；本 skill 只讲一层机制——整体持久 / 局部速决的分离。
- 与 `积极防御与诱敌深入`(u17) 的区别: u17 讲劣势方如何以退让保存军力、待机反攻；本 skill 讲同时把局部转为主动进攻。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定层次与全局态势**
   - 完成标准: 明确写出"整体层面我处于劣势 / 被动"，并给出依据（资源、规模、时间）。若整体实际占优或双方接近，退出本 skill。

2. **在整体层取持久 / 防御姿态**
   - 完成标准: 写出整体层"求稳"的具体做法（不争一时胜负、避开整体决战、以时间换条件），并接受一段时间的整体被动。

3. **选定局部战场，取速决 / 进攻姿态**
   - 完成标准: 至少选定一个局部（细分市场 / 单点产品 / 单场行动），给出集中优势力量的方式与"快打快收"的退出条件。
   - 判停条件: 若局部速胜无法向整体转化、或对手会以更大规模报复打断积累，则回到"两手准备"重新评估，不要机械承诺"小胜必成大胜"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 双方实力接近、缺乏整体劣势时——层次分离失去意义，直接按常规竞争即可。
- 短期一次性对抗——没有"长期整体 + 多个局部"的结构可分。
- 只有单一战场、不存在可独立行动的局部时——无法在局部制造相对优势。

### 作者在书中警告的失败模式

- **军事冒险主义（"御敌于国门之外""不丧失寸土"）**（第一卷《中国革命战争的战略问题》，ce08）：整体劣势时拒绝层次区分、拒绝退却，与强敌硬拼硬守，把决战提前到不利时机——第五次反"围剿"因此"丧失了整个根据地，使红军做了一万二千多公里的长征"。
- **军事保守主义与逃跑主义**（第一卷《中国革命战争的战略问题》，ce09）：反向失败的一端——畏敌如虎、处处设防、被动应付，或名为灵活退却实为只保不战，同样丧失主动、根据地不保。

### 作者的盲点 / 时代局限

- **"局部速胜能否线性累积为全局优势"未被证明**：假定多次局部胜利必然转化为战略优势，未排除对手以更大规模报复或外部干预打断累积过程（BOOK_OVERVIEW §3 未证明假设 3；units-merged u21 风险提示）。
- 该机制**强军事语境**，依赖"广土众民、以空间换时间"这类当时条件；迁移到商业 / 竞争场景需把"军力 / 地形"替换为相应的资源与条件（BOOK_OVERVIEW §3 时代局限 1）。

### 容易混淆的邻近方法论

- 歼灭战优先（局部以歼灭为目标）；持久战：先判性质再定阶段（节奏控制）；积极防御与诱敌深入（主动退让待机）；集中优势兵力（局部形成绝对优势）。
