# 缩小打击面，区别对待（扩大教育面）

## R — 原文 (Reading)

> "总的打击面，一般不能超过户数百分之八，人口百分之十。……在区别待遇和总的打击面上，半老区亦是如此。"
>
> — 毛泽东，第四卷《新解放区土地改革要点》

---

## I — 方法论骨架 (Interpretation)

- 当要处置一批对象（人、事物、违规行为）时，不要按"有问题/没问题"一刀切，而是先分档。
- 分档的核心是责任与性质：最严重的少数（首恶）必须处理，被裹挟的、轻微的、可教育转变的，尽量不列入处置面。
- 处置面要有上限——不是"有多少处理多少"，而是设一个明确的最小比例/名额，作为纪律约束。
- 与之相对，把可争取、可转化、可挽救的对象尽量纳入"教育面"，降低对抗面、减少误伤、防止扩大化。
- 原则是"首恶必办、胁从不问"：对少数必须处理，对多数以区别待遇争取过来。
- 这不是放弃是非：手段是区别，标准仍是分清责任；放过首恶不是"缩小打击面"，而是放弃原则。
- 数量约束是这条方法的特色：把"要谨慎"这种态度，变成"处置面不超过某个明确比例"的可核查约束。

## A1 — 书中的应用 (Past Application)

### 案例 1: 晋绥土改整党纠正三个"左"的偏向
- **问题**: 土改整党运动中出现扩大打击面、侵犯工商业、乱打乱杀三类"左"的偏向，其中"在划分阶级成分中……把许多并无封建剥削或者只有轻微剥削的劳动人民错误地划到地主富农的圈子里去"，错误地扩大了打击面。
- **方法论的使用**: 作者逐一剖析三个偏向的内容与根源，把"划错成分、扩大打击面"单列为必须纠正的偏差，并肯定侵犯工商业、乱打乱杀同样须改。
- **结论**: 纠偏后工作"走上了健全发展的轨道"，并据此提炼出"按照实际情况决定工作方针"这一最基本的工作方法。
- **结果**: 三个偏向被纠正，打击面收窄，运动回到正轨。（c18，第四卷《在晋绥干部会议上的讲话》）

### 案例 2: "五反"宽严清单与五类划分
- **问题**: 要处置大量工商户，既须打击少数严重违法者，又不能扩大打击面、造成混乱。
- **方法论的使用**: 作者把政策写成对偶宽严清单（"过去从宽，今后从严；多数从宽，少数从严……"），并按北京五万工商户的实际比例划为守法、基本守法、半守法半违法、严重违法、完全违法五类，前二类约百分之七十，据此区别对待。
- **结论**: 以"团结多数、孤立少数"的方式把处置面压到极少数，减少混乱。
- **结果**: 形成宽严有别、比例明确的处置方案；同时明令不得用肉刑逼供、县区乡暂不进行、中等城市分批进行。（c23，第五卷《关于"三反""五反"的斗争》）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司要追责一次重大合规或生产事故中牵涉的一批员工，纠结"是不是都处理"。
2. 平台/社区要处罚一批违规用户、群组或内容，担心处罚面太大引发反弹。
3. 组织整顿纪律、清理历史遗留问题，牵涉人数多、情况轻重不一。
4. 学校/机构要处理一批犯了同类错误的学生或成员，想兼顾原则与稳定。
5. 团队内部出了问题，用户情绪化地想"全开掉""杀一儆百"。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要全都处理""是不是都得开除""一锅端最省事""斩草除根""杀一儆百""秋后算账"
- "会不会把人推到对立面""扩大打击面会不会出事""怎么处置才不至于人人自危"
- EN: "punish everyone / mass crackdown / zero tolerance / avoid alienating the majority / how far should we crack down / narrow the target"

### 与相邻 skill 的区分

- 与 `exploit-contradictions`（利用矛盾、争取多数、反对少数、各个击破）的区别: 后者的对象是**对手群体内部**，先分化其矛盾；本 skill 处理的是**自己决定要处置的一批对象**，重心在把处置计划收缩到最小、把多数纳入教育面。
- 与 `united-front-three-tier`（统一战线三分法）的区别: 后者对**整个局面**分层配置"发展/争取/孤立"；本 skill 只给"处置面设上限 + 区别待遇"这条数量纪律。
- 与 `quantitative-grasp`（胸中有数）的区别: 后者是一般性的"关键问题要有数量分析"；本 skill 是它的一种典型应用——用一条明确的数量上限（如处置面比例）约束政策。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **列对象清单并按责任分档**
   - 完成标准: 把全部涉事对象列入清单，分成三档——首恶/主责、被裹挟或轻微、可教育可转化；每档都有具体名单或判断依据。

2. **给处置面设一个明确的上限**
   - 完成标准: 写出一个可核查的最小比例或名额（如"实际处置不超过总数的 X%""处分名单不超过 N 人"），并说明依据。
   - 判停条件: 若无法量化，退而给出"最小必要"的相对表述，并注明此为近似值。

3. **对可教育者确定"不追究/从轻"处置**
   - 完成标准: 对第二、三档逐类给出具体待遇（不追究、从轻、以教育代替处分），把它们明确纳入"教育面"而非"打击面"。

4. **复核对首恶的标准**
   - 完成标准: 确认处置名单中剩下的确实是责任最重、性质最严重的少数；若名单越列越长 → 停，回到步骤 1 重新分档。

5. **定处置程序，避免一刀切**
   - 完成标准: 给出分档对应的处理程序（如"首恶必办、胁从不问"），并明确禁止类比逼供、扩大化、连带的做法。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **不要把它当成"和稀泥"或无原则纵容**：如果实际上是非不清、谁也不处理，或以"教育面"为名放过明显的首恶，这已背离本方法。本方法的前提仍是分清责任，只是把处置控制在最小范围；"放弃是非、无原则纵容"是被坚决排除的反场景。
- 需要保密或极速决断、来不及甄别的场合，分档本身可能延误。
- 是非标准本身就不清晰、需要先无原则妥协的场合，不适用。

### 作者在书中警告的失败模式

- **政策和策略上"左"的偏向**：侵犯中农、侵犯民族资产阶级、对地主富农不加区别、忽视缩小打击面、工作步骤上的急性病，"有时成了严重的冒险主义倾向"（第四卷《关于情况的通报》，ce24）。
- **"怀疑一切、打倒一切"**：不作具体分析地扩大打击面，把"一切"当权派不加区分地否弃，作者指其"一定要走向反面"（第七卷《论夺权》等，**静火版，记录稿，可靠度最低**，ce32）。

### 作者的盲点 / 时代局限

- 精确比例（8%/10%）是特定群众运动的产物，脱离当时语境即失效（units-merged u31 风险提示）。
- "打击面"框架预设存在可被强制处置的对象，在平等、无强制力的协作关系中需改写为可申诉的处置规则。
- "人民/民主"以自上而下的政治划界为前提，边界由执掌一方掌握、缺独立仲裁程序，以群众运动替代常规法治程序（BOOK_OVERVIEW §3 立场盲点 3）。
- 第七卷引文出自**静火版非官方汇编、记录稿，可靠度最低**（BOOK_OVERVIEW §3 时代局限 4）。

### 容易混淆的邻近方法论

- **利用矛盾、争取多数、反对少数、各个击破**：处理对手阵营内部分化；本 skill 处理自己决定处置的一批对象、给处置面设上限。
- **胸中有数（数量分析）**：一般性的量化要求；本 skill 是"用数量上限约束处置范围"的专门应用。
