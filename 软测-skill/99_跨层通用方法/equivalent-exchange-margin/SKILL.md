# 等价交换与留有余地

## R — 原文 (Reading)

> "用'无偿'来搞共产主义不行。猪只有一条，你有他就没有了。凡是劳动，总要等价交换的。"（第六卷《在第二次郑州会议上的讲话》）
>
> "提得低，由实践把它提高。"（第六卷《在八届六中全会上的讲话》）
>
> — 毛泽东（静火版，记录稿）

---

## I — 方法论骨架 (Interpretation)

这套方法由两条互相咬合的原则组成，针对的是"占便宜"和"虚报"两种病灶。

- **等价交换**：凡是涉及一方劳动或资源向另一方转移的协作，都要有对价——不能无偿占有别人的劳动成果。它反对的是"一平二调"式的平调（白拿）。落到今天，就是跨部门调资源要记账/对等回报，激励要与贡献相称，合作要互利而非单方奉献。
- **为什么不能白拿**："猪只有一条，你有他就没有了"——无偿占有必然损害被占有一方的积极性，长期看会逼出瞒报、藏私和对抗。
- **留有余地**：制定目标时，宁可先按"现实可能性"定一个稳妥值、留出弹性，让实践去超额完成，再据此上调；而不是先定一个高高在上的指标，落空后层层加码。
- **反直觉处**：主动把指标定低不是保守，而是一种防止虚夸的策略——高指标会被压力传导成假数据（"上面一吹二压三许愿，下面很难办"）。
- **前提是能结算**：等价交换要求转移可核算；对难以定价的对象，需要另找记录贡献或互惠的口径。

通用表述：合作须互利、不可无偿占用；指标不可定太满，宁可留弹性让实践去提高，以换取数据真实和可持续的积极性。

## A1 — 书中的应用 (Past Application)

### 案例 1: 第二次郑州会议——"凡是劳动，总要等价交换"
- **问题**：人民公社化中出现"一平二调"、无偿调拨（共产风），剥夺了农民。
- **方法论的使用**：作者以"猪只有一条"的通俗例子说明无偿占有的荒谬，把"等价交换"确立为纠正共产风的准则；并举军官寄钱回家被公社扣下引起反映为例，强调财产权利不可侵犯。
- **结论**：队与队之间应是买卖关系，调剂要协商，按等价交换纠正"一平二调"。
- **结果**：主张以等价交换原则落实纠偏。（原文未展开纠偏全面落实的经过）
- **来源**：第六卷《在第二次郑州会议上的讲话》（静火版）

### 案例 2: 党内通信——只管现实可能性，不讲假话
- **问题**：高指标层层下压，下面被迫吹牛说假话。
- **方法论的使用**：作者越级直接给六级干部写信，要求按现实可能性包产、不讲假话；反对上面下死硬命令。
- **结论**：以一年年积累经验、逐步认识客观必然性为方针。
- **结果**：作者自称"唱低调，意在真正调动积极性"。（原文未展开各地执行后的具体情况）
- **来源**：第六卷《党内通信——致六级干部的公开信》（静火版）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计跨部门协作/资源调拨规则时，担心一方长期"白占"另一方的劳动或资源。
2. 制定团队或个人的季度/年度 KPI，用户纠结"指标定高还是定低、要不要留余量"。
3. 组织里出现虚报数据、层层加码、为完成指标而造假的现象，用户想从机制上根治。
4. 分配奖金、激励或收益时，用户想建立"贡献与回报对等"、让人服气的规则。
5. 与外部伙伴合作，用户需要判断合作条款是否公平、是否被单方占便宜。

### 语言信号 (用户的话里出现这些就应激活)

- "这样分配公平吗／谁占了便宜"（is this fair / who's freeloading）
- "指标该定多高"（how ambitious should the target be）
- "为什么下面总报假数据"（why does the data keep getting inflated）
- "怎么设计激励才不内耗"（how to design incentives without gaming）
- "合作条款是不是不对等"（is this partnership lopsided）

### 与相邻 skill 的区分（初稿）

- 与 `balanced-integration`（综合平衡与冷热结合，u38）的区别：那讲计划内部各部门的比例平衡，本 skill 讲两方之间交换的公平与目标的弹性。
- 与 `grasp-the-numbers`（胸中有"数"，u48）的区别：那是数量分析的方法，本 skill 是分配规则与目标机制的设计。
- 与 `overall-coordination`（统筹兼顾，u37）的区别：那是多目标兼顾，本 skill 是两方之间的对等交换。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别是否存在无偿转移**
   - 检查本轮协作/分配里有没有"白占便宜"（一方无偿占用另一方的劳动/资源/成果）。
   - 完成标准: 列出所有涉及资源或劳动跨方转移的条目。

2. **让等价可结算**
   - 对这类转移建立可核算的交换规则（内部计价、记账、对等回报或明确补偿）。
   - 完成标准: 每条转移都有对应的对价或补偿口径。
   - 判停条件: 若某转移无法定价（公共品、纯知识共享）→ 不硬套计价，改按贡献记录或轮换互惠处理（见 B 段）。

3. **指标先提低**
   - 制定目标时先按"现实可能性"定一个稳妥值、留出弹性，而不是先定高值再层层加码。
   - 完成标准: 目标值有依据、有余量，并写明"超额完成后再上调"的机制。

4. **建反馈上调机制**
   - 用实践结果去提高指标，而不是用压力去逼高指标。
   - 完成标准: 明确规定何时、依据什么数据上调目标，并明令禁止因指标落空而要求造假。

5. **检查副作用**
   - 复核低压指标是否过低到失去牵引力，或等价结算是否制造了新的内耗。
   - 完成标准: 指标仍能驱动行动，跨部门关系未因计价而恶化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **无法定价的场景（公共品、纯知识共享、志愿服务）**：硬套"等价交换"会把不易计价的贡献算坏，反而伤协作。
- **紧急状态/危机中的统一调配**：救灾、救火式的资源集中不宜按日常等价规则处理。
- **把"留有余地"当不作为的借口**：指标提低是为了让实践超额，不是为逃避目标；过低到失去牵引就偏离本方法。

### 作者在书中警告的失败模式

- ce28 共产风/一平二调：无偿占有别人劳动成果，否认等价交换与按劳分配，引起群众坚决抵抗（静火版，可靠度较低）。
- ce29 "五风"（共产风、浮夸风、命令风、特殊风、瞎指挥风）：以行政命令推动经济、报喜不报忧、虚报浮夸。
- ce30 忘记实事求是、片面思想：把主观愿望当现实可能性，走过弯路、丧失主动。

### 作者的盲点 / 时代局限（含可靠度风险）

- **可靠度风险**：本条全部出自第 6 卷"静火版"非官方汇编的讲话记录稿，可靠性较低，标点与转录存在疑误，引用时须标注版本、视为记录文献而非作者定稿（BOOK_OVERVIEW 第 3 节·时代局限 4）。
- "等价交换"在难定价场景（公共品、知识协作）操作化困难（units-merged u39 风险提示）。
- 该论述深嵌于当时"反共产风"的具体政策语境，迁移时须剥离具体制度安排。

### 容易混淆的邻近方法论

- `balanced-integration`（综合平衡与冷热结合，u38）：讲计划内部的比例平衡，非交换公平与目标弹性。
- `grasp-the-numbers`（胸中有"数"，u48）：是数量分析方法，非分配与目标机制。
- `overall-coordination`（统筹兼顾，u37）：是多方兼顾，非两方对等交换。
