# 自力更生为主，外援为辅（丢掉幻想，准备斗争）

## R — 原文 (Reading)

> "我们的方针要放在什么基点上？放在自己力量的基点上，叫做自力更生。"
>
> — 毛泽东，第四卷《抗日战争胜利后的时局和我们的方针》

---

## I — 方法论骨架 (Interpretation)

- 规划长期战略时，先问一句：这件事的立足点放在哪里？答案应是"自己力量的基点"，而不是外部的承诺或援助。
- 外部资源可以有，也应当用：技术、资金、渠道都可引进、借鉴、合作——但定位是辅助，不是命脉。
- 关键能力（一旦外部断供就致命的那些）必须自建，不能把身家押在别人手里。
- 对外部合作方不抱"永远可靠"的幻想：不是假定对方一定加害，而是不把自身安危建立在对方的善意之上。
- 次序很重要：不是"先合作、再自强"，而是先组织自身力量、取得实力与主动，才有平等合作可谈。
- 不抱幻想与争取合作并不矛盾——丢了幻想，反而能更清醒地判断哪些合作可靠、哪些是陷阱。
- 对标的是"依靠外力当靠山"的反面做法：把希望寄托在外部，一旦靠山变动即全盘皆输。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 抗战胜利后，方针不放在美蒋而放在自己力量
- **问题**: 日本投降后的时局中，蒋介石"完全是依靠美国帝国主义的帮助，把美国帝国主义作为靠山"，有人把希望寄托在外部影响或援助上。
- **方法论的使用**: 作者明确提出问题"我们的方针要放在什么基点上"，回答是"放在自己力量的基点上，叫做自力更生"，主张依靠自己组织起来的人民力量去打倒反动派。
- **结论**: 强调自力更生，同时指出"我们并不孤立"——但立足点必须在自己力量的基点上。
- **结果**: 确立了不依靠外部靠山、靠自己组织力量的方针；同时警惕"不相信帝国主义的'好话'和不害怕帝国主义的恐吓"。（第四卷《抗日战争胜利后的时局和我们的方针》）

### 案例 2: 对"民主个人主义"拥护者的幻想作批评
- **问题**: 一部分知识分子对美国帝国主义者存着幻想，容易被"某些甜言蜜语所欺骗"，似乎不经过斗争，对方也会讲平等、讲互利。
- **方法论的使用**: 作者把这种幻想点破：不经过严重的长期的斗争，对方不会自动平等待人；主张"丢掉幻想，准备斗争"，先组织力量斗争取得实力，才谈得上平等互利。
- **结论**: 对外部不抱幻想，是达成平等合作的前提而非障碍。
- **结果**: 确立了"先斗争、后平等合作"的次序，揭露依靠外力的幻想。（第四卷《丢掉幻想，准备斗争》；参见第七卷《发展自己的工业和农业不要依靠外国》——外国技术可进口，但关键能力"要自己搞"，**静火版，记录稿**）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司的关键器件、核心软件或原材料依赖单一海外供应商，要规划中长期战略。
2. 业务过度依赖单一平台（流量、账号、渠道）或单一客户，纠结要不要分散、要不要自建。
3. 创业公司融资、资源依赖单一投资方或合作方，纠结自主性与依赖度的取舍。
4. 个人职业发展过度依赖单一雇主、平台或某个"贵人"的承诺。
5. 谈判中对方口头承诺长期支持，用户不确定能否把它当作规划前提。

### 语言信号 (用户的话里出现这些就应激活)

- "离不开这个供应商/平台""被卡脖子怎么办""关键能力要不要自研""他们答应了会支持我们""要不要相信他们"
- "不要依赖别人""能不能靠外部解决""要不要自己搞""把命脉握在自己手里"
- EN: "single point of failure / over-reliance on a vendor / should we build it in-house / don't count on them / we're locked in / self-reliance / drop the illusions"

### 与相邻 skill 的区分

- 与 `worst-case-preparation`（两手准备、向最坏可能准备）的区别: 后者管"行动前的风险预案与胜算"; 本 skill 管**方针立足点与关键能力的归属**——即使没有迫近风险，也要把命脉握在自己手里。
- 与 `独立自主`（联盟中保持独立）的区别: 后者处理"已成联盟的伙伴之间如何不被同化"; 本 skill 处理"自身力量与外部依赖的根本配置"。
- 与 `principal-contradiction`（抓主要矛盾）的区别: 后者的对象是任务方向; 本 skill 的对象是"哪些能力必须自建、哪些可外借"。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **识别关键能力/命脉清单**
   - 完成标准: 列出"一旦外部断供、撤回或变卦就会致命"的能力或资源，逐项标注其当前由谁掌握。

2. **判定立足点现状**
   - 完成标准: 对每项命脉，判定当前是否把立足点押在外部（单一供应商/平台/投资方/他人）；标出风险等级。

3. **为关键能力定自建路径与里程碑**
   - 完成标准: 对风险等级最高的命脉，给出自研/自建的路径、分阶段目标与最低可接受的自给程度，而非只有一句"要自主".
   - 判停条件: 若某项并非命脉、自研成本远高于收益 → 明确列为"可外借"，不强行自建（避免为自研而自研）。

4. **明确外部部分的"辅助"定位与替代方案**
   - 完成标准: 对可引进的外部技术/资源，写明其辅助定位，并至少准备一条替代或退路（多源、可迁移、备份）。

5. **做"丢掉幻想"检查**
   - 完成标准: 列出规划里对合作方"永远可靠/必定支持"的隐含假设，逐条写出"若对方不这么做，我们怎么办"。
   - 判停条件: 若某条假设无法承受被推翻，回到步骤 3 把它升为命脉处理。

6. **安排次序：先立实力，再谈平等合作**
   - 完成标准: 说明在谈判/合作前，用什么具体动作先建立自身实力与筹码，再进入平等互利条款。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- ⚠️ **不要把"自力更生"误读为闭关排外、拒绝一切外部合作**。原文强调的是"把方针放在自己力量的基点上"，不等于拒绝引进、拒绝交往；关键能力自建与积极争取外援、平等合作并行不悖。以本 skill 为由切断所有外部合作、闭门造车，是典型的误用。
- 关键能力并非命脉、外部方案明显更优更省时，却为"自主"而强行自研——这是成本不划算的过用。
- 需要快速借助外部成熟能力渡过生存关口的紧急阶段，硬扛自建可能适得其反。

### 作者在书中警告的失败模式

- **对外部存幻想**：被"某些甜言蜜语所欺骗，似乎不经过严重的长期的斗争，这些帝国主义分子也会和人民的中国讲平等，讲互利"（第四卷《丢掉幻想，准备斗争》）——正是本方法"丢掉幻想"所针对的反面。
- **依靠外力当靠山**：蒋介石"完全是依靠美国帝国主义的帮助，把美国帝国主义作为靠山"（第四卷《抗日战争胜利后的时局和我们的方针》）——把立足点押在外部，是自力更生的对照反例。
  - 注: 本单元在 units-merged 中无专属 counter-example（相关反例为"—"），以上取自 R 段原篇目中作者本人明确批评的失败模式。

### 作者的盲点 / 时代局限

- "不抱幻想"带有默认敌对预设，在需要长期协作的场景可能**自我实现**：预设对方不可信，反而把合作关系推向对抗（units-merged u40 风险提示）。
- "先斗争后合作"的次序在自身毫无实力、无筹码时难以启动，原文未给"弱到无法斗争"时的出路（同上）。
- 论断绑定 1930–40 年代的两极格局与具体力量对比，脱离该条件直接迁移可能失真（BOOK_OVERVIEW §3 时代局限 1）。
- 第七卷《发展自己的工业和农业不要依靠外国》出自**静火版非官方汇编、记录稿，可靠度较低**（BOOK_OVERVIEW §3 时代局限 4）。

### 容易混淆的邻近方法论

- **两手准备（向最坏可能准备）**：风险预案的时间视角；本 skill 是能力归属与立足点的战略视角。
- **独立自主（联盟中保持独立）**：联盟内部的自主权问题；本 skill 是"命脉由谁掌握"的全局配置。
