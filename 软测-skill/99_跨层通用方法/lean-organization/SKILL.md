# 精兵简政（机构—任务匹配）

## R — 原文 (Reading)

> "假若我们缩小自己的机构，使兵精政简……而因克服了鱼大水小的矛盾，使我们的战争的机构适合战争的情况。"
>
> — 毛泽东，第三卷《一个极其重要的政策》

---

## I — 方法论骨架 (Interpretation)

"精兵简政"处理的不是"人多人少"，而是"机构与任务是否相称"。

- **判据是匹配，不是数量**：核心矛盾叫"鱼大水小"——机构（水）比任务和环境（鱼）还大，运转就笨重、费资源。要不要瘦身，看的是机构是否超出任务所需，而不是单纯看编制表。
- **机构服务于任务**：先把当前的核心任务和环境约束讲清楚，再谈机构该多大；任务变了，机构要跟着变，而不是让任务迁就既有机构。
- **五项验收**：精简、统一、效能、节约、反官僚主义。减了人，但若造成职责割裂（不统一）、办事变慢（失效能）、或反而催生新的官僚流程，就不算达标。
- **障碍常在习惯**：改革最大的阻力往往来自"为现状和习惯所束缚"——既得格局和惯性让人不敢真动。
- **易被误用**：它容易被简化成"裁员降本"，从而砍掉不该砍的能力；本方法恰恰要求保护与任务匹配的关键能力。

通用表述：组织规模应以任务和环境为标尺随时校准，用"是否更能完成任务"验收瘦身，而非用人数是否下降来验收。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 晋冀鲁豫边区精兵简政的模范与"鱼大水小"
- **问题**：根据地缩小，庞大的战争机构与战争情况发生矛盾，物质困难将更加严重。
- **方法论的使用**：作者举晋冀鲁豫边区领导同志"抓得很紧、做出了精兵简政的模范例子"，把精兵简政论证为"使机构适合情况"；并直指真正的障碍是"为现状和习惯所束缚"，以孙行者变小虫战铁扇公主、黔驴被小老虎吃掉作比。
- **结论**：机构变小反而"更加扎实"，更不易被战胜。
- **结果**：确立"缩小机构、使兵精政简"以适应战争情况的方向。
- **来源**：第三卷《一个极其重要的政策》

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司/团队高速扩张后变得臃肿、人浮于事，用户想判断"该按什么标准瘦身、砍哪里"。
2. 用户面对"要不要裁员、裁多少、怎么裁"的决策，担心一刀切砍掉关键能力。
3. 组织层级、审批环节越来越多，用户感觉"机构比要干的事还大"，想精简流程与编制。
4. 任务或外部环境发生大变化（市场收缩/业务转型），用户需要重新校准机构规模。
5. 用户被要求做"降本增效"的方案，但不确定是单纯减人还是重构机构。

### 语言信号 (用户的话里出现这些就应激活)

- "组织太臃肿了，怎么瘦身"（the org is bloated / how to slim down）
- "要不要裁员／裁多少人"（should we do layoffs / headcount reduction）
- "机构比事情还大／人浮于事"（too many people for the work / overstaffed）
- "降本增效怎么做才不伤业务"（cost-cutting without hurting the business）
- "编制和任务对不上"（the structure doesn't match the work）

### 与相邻 skill 的区分（初稿）

- 与 `party-committee-methods`（党委会工作方法，u34）的区别：那是会议与领导方法合集（含"精兵简政"一款），本 skill 专讲机构与任务的匹配。
- 与 `grasp-the-numbers`（胸中有"数"，u48）的区别：那是用数量分析找质量界限的通用要求，本 skill 是把该要求落到"机构该多大"。
- 与 `overall-coordination`（统筹兼顾，u37）的区别：那是多目标权衡，本 skill 是单一目标——让机构匹配任务。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断"鱼大水小"**
   - 对比机构规模与当前任务/环境的实际需要，找出机构大于任务的具体环节。
   - 完成标准: 能逐条指出哪些部门/层级/编制与任务不匹配（尽量附数据）。

2. **厘清任务与环境的边界**
   - 先写清楚现在的核心任务清单和外部环境约束，再谈机构（机构服务于任务，不是反过来）。
   - 完成标准: 有一份"当前核心任务 + 环境约束"的明确清单。

3. **设计精简方案**
   - 对与任务不匹配的机构做合并、撤销、下移或缩小；同时保留并加强匹配任务的关键能力。
   - 完成标准: 方案的每一条都对应到具体机构/编制，并说明它如何更贴合任务。

4. **按五项验收**
   - 用精简、统一、效能、节约、反官僚主义五项逐一核对。
   - 完成标准: 五项均未被"伤及能力"破坏。
   - 判停条件: 若某项缩减损害了关键能力或整体效能 → 回退该项，不做此缩减。

5. **跟踪与纠偏**
   - 落地后跟踪任务完成情况，出现能力缺口就补回。
   - 完成标准: 经过一个任务周期，核心任务的产出没有下降。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **单纯为财务报表或指标砍人数**：本方法判据是"机构是否与任务匹配"，不是"人多人少"，按人数硬砍会砍掉能力。
- **任务正快速扩张期**：任务在增长时机构可能需要同步扩充，机械"瘦身"反而与任务脱节。
- **以"精简"为名排除异己、削弱必要职能**：这是对方法的滥用，会制造新的不匹配而非解决不匹配。

### 作者在书中警告的失败模式

- 真正障碍是"为现状和习惯所束缚"（c14）：机构改革的最大阻力常来自既有格局与惯性，不敢动真格则改革空转。
- ce31 官僚主义诸表现（高高在上、机构重叠、公文旅行、办事拖拉）：机构臃肿是官僚主义的温床，而"滋生官僚主义的土壤是肥沃的"。

### 作者的盲点 / 时代局限

- 五项验收标准（精简、统一、效能、节约、反官僚主义）偏定性，缺乏可量化准则（units-merged u49 风险提示）。
- "机构—任务匹配"的合适规模没有量化判据，减编可能伤及能力；且原始论证依赖战时根据地这一特定组织形态，脱离该条件需重新界定（BOOK_OVERVIEW 第 3 节·时代局限 1）。

### 容易混淆的邻近方法论

- `party-committee-methods`（党委会工作方法，u34）：是会议与领导方法合集，非机构规模判定。
- `grasp-the-numbers`（胸中有"数"，u48）：是量化分析的通用要求，非组织调整方案。
- `overall-coordination`（统筹兼顾，u37）：是多目标权衡，本 skill 是单一目标——机构匹配任务。
