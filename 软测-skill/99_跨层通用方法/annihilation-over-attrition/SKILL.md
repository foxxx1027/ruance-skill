# 歼灭战优先（以歼灭有生力量为目标）

## R — 原文 (Reading)

> "对于人，伤其十指不如断其一指；对于敌，击溃其十个师不如歼灭其一个师。"
>
> — 毛泽东，第一卷《中国革命战争的战略问题》

---

## I — 方法论骨架 (Interpretation)

- 对强敌作战有两条路：一是"击溃"——把对手逼退一下、使它受点损失，事后它还能恢复；二是"歼灭"——彻底打掉对手的**有生力量**（人员与建制部队），使它无法再战。
- 只有歼灭才是净收益。把对手只击溃十次、每次都未伤其根本，等于白白消耗自己（"伤其十指不如断其一指"）。
- 因此优先考虑的不是占了多少地方（地盘可失而复得），而是有没有真正消灭对手的有生力量。
- 打法上：宁可在次要方向暂时让步、放弃某些阵地，也要把优势力量集中到选定的目标上，一次打透，积小胜为大胜。
- 判断胜负的标准随之改变：不看"占了多少"，看对手的战斗力有没有被切实削弱。只赔不赚的"胜仗"很少意义。
- 注意用语分寸："歼灭"含击毙、击伤或俘虏，并不要求肉体上全灭；它针对的是战斗力与建制，不是人本身。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 反"围剿"中的"诱敌深入"——以聚歼敌一路为目标
- **问题**: 红军初起时"根本没有经验"、屡打败仗，且在全局上敌强我弱。
- **方法论的使用**: 作者在实战中否弃与强敌硬拼、只求击溃的打法，转而采用"诱敌深入"——把敌一路放进来，在局部集中兵力把它**聚而歼之**，而不是固守阵地或只把它逼退。
- **结论**: 以消灭进攻之敌的有生力量（而非保住每一寸土地）为作战目标，才能以弱胜强。
- **结果**: 第一次反"围剿"中"诱敌深入"的方针提出并应用成功，到第三次反"围剿"时红军作战原则全部形成（出处：第一卷《中国革命战争的战略问题》，及 c06）。

> 注: 本单元在 units-merged 中无专属佐证案例（佐证案例为"—"），此处取与"以歼灭而非击溃为目标"最贴合的 case 素材作类比。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 资源有限，纠结该把力量摊到多个方向（多产品、多市场、多项目）还是集中做透一个。
2. 在"追求功能 / 规模 / 数量"与"把核心问题彻底解决"之间摇摆。
3. 已经赢了几个小仗（拿下几个客户 / 上了几个功能），但对手的核心能力没被削弱，不知道这样算不算有效。
4. 为了守住已占的"地盘"（既有业务、存量客户）而不敢把资源挪到关键战场。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要多做几个功能""全面铺开还是单点突破"
- "怎么才算赢""这样打有没有用""对手还在，我们却累了"
- "EN: focus, do one thing well, depth over breadth, decisive win, take the win, spread thin"

### 与相邻 skill 的区分

- 与 `principal-contradiction`（抓主要矛盾）的区别: 本 skill 关注**竞争的胜负标准**——有明确对手，纠结"歼灭其有生力量 vs 占地盘/堆规模，哪个才算赢"；若用户没有竞争对手、只是多个待办/方向排序取舍，应调用 principal-contradiction。
- 与 `layer-switching`（层次转换）的区别: 后者讲在整体劣势下把局部转为速决进攻（层次的分离）；本 skill 讲局部进攻时以"歼灭"为目标而非"击溃"。
- 与 `favorable-decisive-battle`（执行有利决战）的区别: 后者管"要不要打这一仗"；本 skill 管"这一仗以什么为目标、怎样才算赢"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **界定"对手的有生力量"是什么**
   - 完成标准: 写出你在本场景中真正要削弱 / 消除的对象（不是地盘、不是表面指标，而是对手再战能力的根源）。
   - 判停条件: 若本场景的目标本来就是"守土 / 铺开覆盖"，直接退出本 skill，改用其他方法。

2. **比较两条路：击溃还是歼灭**
   - 完成标准: 至少列出一个"摊开做多件"的方案与一个"集中打透一个"的方案，并说明各自的净收益（对手能否恢复）。
   - 判停条件: 若集中打透会使你在真正需要铺开的方向上失守，则转出到"抓主要矛盾 / 统筹兼顾"重新权衡。

3. **集中力量打透一个并检验战果**
   - 完成标准: 选定唯一主攻目标、给出集中的资源量，并设定一个"对手再战能力被削弱"的可观察判据（而非"占了多少"）；次要方向明确写出愿意暂时让步的内容。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 目标本身是"铺开覆盖 / 守住底线"（合规、安全、服务可用性、普惠服务）——此时"守土"就是目的，退让次要方向可能造成不可接受的损失。
- 没有明确竞争对象的纯创造 / 合作场景，硬套"歼灭"会扭曲目标。
- 把"歼灭"直接类比到具体的人（团队、用户、员工）身上——本方法针对的是"能力 / 建制"，不是人；须去掉暴力语义后再迁移（units-merged u20 风险提示）。

### 作者在书中警告的失败模式

- **拼消耗与击溃战（"乞丐与龙王比宝"）**（第一卷《中国革命战争的战略问题》，ce12）：与强敌拼资源、拼消耗，追求"击溃"而非"歼灭"，即便算胜仗也"很少意义"，因为没有缴获或缴获不超过消耗——正是本方法要避免的反面。

### 作者的盲点 / 时代局限

- 该论断**绑定 1930–40 年代的物质与格局条件**（武器、通信、后勤、广土众民的农村社会）。"以战养战""集中优势兵力"等建立在特定资源禀赋上，脱离条件直接迁移可能失真（BOOK_OVERVIEW §3 时代局限 1）。
- 假定"多次局部胜利必然线性转化为战略优势"，未排除对手以更大规模报复或外部干预打断累积过程（BOOK_OVERVIEW §3 未证明假设 3）。

### 容易混淆的邻近方法论

- 抓主要矛盾与集中力量（选方向）；层次转换（战略持久 / 战役速决）；执行有利决战，避免不利决战（要不要打）；两手准备（风险管理）。
