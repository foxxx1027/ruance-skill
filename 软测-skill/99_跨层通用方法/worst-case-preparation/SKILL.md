# 两手准备（向最坏可能准备·不打无准备无把握之仗）

## R — 原文 (Reading)

> "向着最坏的一种可能性作准备……正是为着争取好的可能性"；"不打无准备之仗，不打无把握之仗，每战都应力求有准备，力求在敌我条件对比下有胜利的把握。"
>
> — 毛泽东，第二卷《关于打退第二次反共高潮的总结》；第五卷《关于农业合作化问题》

---

## I — 方法论骨架 (Interpretation)

- 面对不确定的局面，同时准备"两手"：一手争取最有利的结果，一手准备应付最坏的情况（谈崩、断供、资金断裂、合作方反悔）。
- 反直觉的核心："向最坏准备"不是悲观，也不是破坏关系，而恰恰是争取好结果的条件——你把最坏情况准备充分了，对方反而不敢轻易翻脸，好的可能才更接近现实。
- 行动准则：不打无准备之仗，不打无把握之仗；出手前力求准备充分、胜算在手。
- 资源上：关键资产（资金、渠道、供应、人脉）分散布置，不把一切都押在单点上。
- 成功的样子：坏结果真来了，你有预案、能扛住；好结果来了，你也接得住、不因准备不足而错过。
- 要警惕它被当作拖延的借口（"再准备准备"）——准备是为了行动，不是为了让行动无限推迟。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 打退第二次反共高潮——向着最坏的可能性作准备
- **问题**: 皖南事变后，有人只顾一种可能性（以为关系不会破裂），或误以为做最坏准备会破坏团结。
- **方法论的使用**: 作者指出必须同时准备应付最坏情形（破裂），并把这种充分准备当作争取好的可能性的条件。
- **结论**: 做最坏的准备不是抛弃好的可能，而正是为着争取好的可能并使之变为现实。
- **结果**: 充分准备对付破裂，"就使国民党不敢轻于破裂"，好的可能性得以实现（出处：第二卷《关于打退第二次反共高潮的总结》，及 c10）。

### 案例 2: "深挖洞、广积粮、不称霸"——分散储备
- **问题**: 面对可能的封锁与突袭风险，如何降低单点被击穿的风险。
- **方法论的使用**: 以分散储备（广积粮）、不把一切资源押在单一方向（分散布置）来应对最坏情况。
- **结论**: 关键资源分散布置，是抵御最坏情况的具体做法。
- **结果**: 形成分散储备、留有余地的备战备荒方针（出处：第七卷《深挖洞，广积粮，不称霸》，**静火版，记录稿**，可靠度较低，及 g47）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 创业/项目现金只够撑几个月，纠结要不要分资源去做"资金断裂"预案。
2. 谈一个重要合作或大合同，对方可能反悔或毁约，不确定要不要先备一手。
3. 关键资源依赖单一供应商 / 单一大客户 / 单一平台，该不该做备份。
4. 重要谈判或投标前，是否要在"争取最好结果"之外，先想清楚"谈崩了怎么办"。
5. 团队只押一个方向，纠结"要不要留后手"以及"现在出手有没有把握"。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要做个最坏的打算""万一他反悔了怎么办"
- "留一手""备胎 / 备份 / 预案""是 all in 还是留退路"
- "现在动还是再等等""这样做有没有把握"
- "EN: worst-case plan, contingency, backup plan, hedge, plan B, downside protection, don't bet the company"

### 与相邻 skill 的区分

- 与 `执行有利决战，避免不利决战`(u44) 的区别: u44 管"这次摊牌要不要打"（按把握程度分类、排除 all-in）；本 skill 管"行动之前/平时怎样为不确定性做两手准备"。
- 与 `战略上藐视敌人，战术上重视敌人`(u24) 的区别: u24 是心态与判断的两层分离；本 skill 是具体的风险管理动作。
- 与 `抓主要矛盾与集中力量`(u11) 的区别: u11 讲把力量集中到一个方向；本 skill 讲在关键资源上保留分散与备份以抗风险，二者可在不同层面并用。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出关键不确定性**
   - 完成标准: 写出 1–3 个最可能发生的最坏情况（对方反悔、资金断裂、供应中断等），每个都具体到可识别的触发信号。
   - 判停条件: 若该决策后果可逆、损失完全可以承受，直接退出本 skill（不值得为它准备）。

2. **为每个最坏情况配一条"应对手"（预案）**
   - 完成标准: 每个最坏情况都对应一条具体动作与所需资源，而不是"到时再说"。

3. **检验"准备是否充分、把握是否在手"**
   - 完成标准: 能明确回答"若最坏情况明天发生，我是否有准备、有把握"——答"是"才行动；答"否"则补准备或暂缓发起。
   - 判停条件: 若必须行动却始终无把握，转到"执行有利决战"类做取舍，或缩小行动规模。

4. **分散关键资源**
   - 完成标准: 至少列出一项并落实一项备份/分散措施（多头备份、分批投入、留出现金/退路）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 后果可逆、损失可承受的日常小决策——套用会变成拖延与过度谨慎。
- ⚠️ 把"做最坏准备"用于人：预设合作方/同事一定会背叛并据此行动——这会自我实现，把本来能成的合作推向破裂。最坏准备的正确对象是"客观风险"，不是"给对方定罪"。
- 把"有准备才有把握"当成永远不出手的理由——准备服务于行动。

### 作者在书中警告的失败模式

- **只顾一种可能性**（第二卷《关于打退第二次反共高潮的总结》，c10 所述问题）：只想着好的一种可能、不做最坏准备，或误以为"做最坏准备会破坏团结"而不做准备。
- **无准备地硬拼**（第一卷《中国革命战争的战略问题》，ce10"拼命主义"）：不顾条件硬打、把勇敢异化为蛮干，是"不打无准备无把握之仗"的反面。

### 作者的盲点 / 时代局限

- "充分准备最坏"未排除过度备战本身会刺激对手、抬高对抗门槛的反作用（BOOK_OVERVIEW §3 未证明假设 5）。
- "有把握才打"可能被用作拖延的借口（units-merged u25 风险提示）——把握的判定依赖估计，估计本身不可靠。
- 相关第六、七卷篇目为**静火版非官方汇编，含记录稿/节选，可靠度较低**（BOOK_OVERVIEW §3 时代局限 4）。

### 容易混淆的邻近方法论

- 执行有利决战，避免不利决战（要不要打这一仗）；战略上藐视敌人，战术上重视敌人（心态双层）；抓主要矛盾与集中力量（集中与保留备份的张力）。
