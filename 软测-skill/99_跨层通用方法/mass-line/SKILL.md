# 群众路线（从群众中来，到群众中去）

## R — 原文 (Reading)

> "将群众的意见（分散的无系统的意见）集中起来（经过研究，化为集中的系统的意见），又到群众中去作宣传解释，化为群众的意见，使群众坚持下去，见之于行动，并在群众行动中考验这些意见是否正确。"
>
> — 毛泽东，第三卷《关于领导方法的若干问题》

---

## I — 方法论骨架 (Interpretation)

- 领导（或产品、决策团队）不是凭空造出方案，而是一个"加工工厂"：原料是群众分散的、零碎的意见，没有充分输入就没有好方案。
- 第一步是"从群众中来"——把一线、用户、基层里那些零散、不成体系的想法和诉求收集上来。
- 第二步是"加工"——不是简单汇总，而是经过研究，把分散意见化为集中、系统的意见（方案）。
- 第三步是"到群众中去"——把方案拿回群众中宣传解释，变成他们认同并愿意执行的东西，落为行动。
- 第四步是"检验"——在群众行动中考验这个意见对不对，而非只在会议室里自我论证。
- 第五步是"再集中"——根据检验结果修正，再收集、再加工、再回到群众，如此循环，一轮比一轮更正确、更丰富。
- 关键在"闭环"与"回程"：意见不仅要上得来，方案还要下得去、并在实践中被检验回来；只上不下的调研不算群众路线。

## A1 — 书中的应用 (Past Application)

### 案例 1: 边区变工队与合作社（群众自愿＋等价交换）
- **问题**: 边区个体分散生产，农民穷苦，抗战条件下劳动力又困难，如何把群众组织起来。
- **方法论的使用**: 作者以陕甘宁边区一年生产运动的实效为据，说明变工队、扎工队、合作社的方针，并把经验总结为两条边界——"群众自愿参加（决不能强迫）"与等价交换。
- **结论**: 组织起来的做法必须从群众经验出发、再回到群众；"三个臭皮匠，合成一个诸葛亮"，向群众综合经验再回到群众。
- **结果**: 变工队使收成比去年多一倍，边区面貌"为之一新"。（c13，第三卷《组织起来》）

### 案例 2: 关心群众生活，注意工作方法
- **问题**: 要动员群众参加革命战争，但若只发号召、不关心群众实际生活，群众不会真心拥护。
- **方法论的使用**: 作者主张领导要真心解决群众柴米油盐、土地、劳动、读书、生小孩等实际生活问题，给群众看得见的物质利益，把"关心群众生活"与"注意工作方法"并提。
- **结论**: 依靠群众，必须先给群众解决实际问题；工作方法是连接号召与群众的桥。
- **结果**: 把"到群众中去"落到解决实际问题上，成为动员群众的前提。（第一卷《关心群众生活，注意工作方法》）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队要为自己并不熟悉的用户群做产品或方案，担心闭门造车。
2. 要制定一项影响基层/一线的政策或制度，却几乎没有一线的输入渠道。
3. 领导层的方案拿到一线执行时遇阻、走样，用户不买账。
4. 想建立一套可持续的用户/员工反馈机制，而不是一次性问卷。
5. 组织内部意见上不来、决策与实情脱节，想打通上下沟通闭环。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么避免闭门造车""怎么听用户/一线的声音""意见怎么总是上不来""方案落地不了"
- "不要拍脑袋决定""怎么让用户参与进来""怎么建立反馈闭环""怎么从基层拿经验"
- EN: "avoid building in a vacuum / ground-up feedback / closed feedback loop with users / bottom-up input / from the masses to the masses"

### 与相邻 skill 的区分

- 与 `investigation-method`（调查研究法）的区别: 后者是"取证"这一前置动作（要不要调查、怎么开调查会）；本 skill 是**完整的双向闭环**——征集→加工→回群众→行动检验→再集中，强调"回程"与检验。
- 与 `general-call-individual-guidance`（一般号召与个别指导）的区别: 后者是"号召—试点—推广"的领导技术；本 skill 是意见的循环上升程序，二者互补但不同。
- 与 `让人讲话`（三不主义、先民主后集中）的区别: 后者聚焦"决策前创造敢讲真话的气氛"；本 skill 覆盖从收集、加工到回群众检验的整条链路。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **明确"群众"是谁并采集分散意见**
   - 完成标准: 指明对象（一线执行者、用户、基层等），并拿到一批具体的、分散的原始意见/诉求，而非二手概括。

2. **把分散意见加工为集中的系统意见**
   - 完成标准: 对原料做研究、归纳为有条理的方案或结论；检查它不是原始意见的简单堆叠。
   - 判停条件: 若原料明显不足（只有少数人的声音）→ 停，回到步骤 1 补充采集。

3. **回到群众中宣传解释、化为行动**
   - 完成标准: 有把方案拿回群众解释、听取反应、推动执行的具体动作；方案在群众中被理解并愿意执行。
   - 判停条件: 若根本没有"回到群众"的通道 → 停，先把通道建起来（否则只是单向调研）。

4. **在行动中检验对错**
   - 完成标准: 给出检验方式（看执行效果、收集反馈），并明确方案中哪些部分被验证、哪些被证伪。

5. **再集中修正，进入下一轮**
   - 完成标准: 依据检验结果修订方案，并说明下一轮从哪里重新"来"、再回到哪里"去"。

6. **守住边界条件**
   - 完成标准: 核对两条底线——组织群众必须"自愿"（不能强迫）；涉及资源转移须"等价"（不能无偿占有群众成果）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无法识别"群众/一线"对象、或反馈渠道不通又来不及建立时，硬套闭环会变成走过场。
- 需要保密、或必须极速决断、来不及走完整闭环的场合。
- 把"听群众"当免责或推责工具：用"大家都这么说"替代自己的判断与责任。

### 作者在书中警告的失败模式

- **官僚主义与命令主义**：不了解下情、"熟视无睹"，工作层层积压（如积压人民来信七万多件），脱离群众、失去群众拥护（第五卷《反对官僚主义、命令主义和违法乱纪》；第一卷《关心群众生活，注意工作方法》，ce26）。
- **官僚主义二十种表现**：高高在上、不作调查研究、强迫命令、浮夸谎报、欺上瞒下等（第六卷《论反对官僚主义》，**静火版，记录稿，可靠度较低**，ce31）。

### 作者的盲点 / 时代局限

- "从群众中来"依赖存在**可识别的群众代表与畅通的反馈渠道**；渠道本身被控制时，"群众意见"可能只是回声（units-merged u32 风险提示）。
- "群众自愿"是**经由教育与引导之后的自愿**，与不受干预的自愿有区别，原文未区分二者（BOOK_OVERVIEW §3 立场盲点 5）。
- 以群众运动替代常规法治程序，削弱可预期性与纠错的中立渠道（BOOK_OVERVIEW §3 立场盲点 3）。
- 第六卷引文出自**静火版非官方汇编、记录稿，可靠度较低**（BOOK_OVERVIEW §3 时代局限 4）。

### 容易混淆的邻近方法论

- **调查研究法**：取证的前置动作；本 skill 是"收集—加工—回群众—检验—再集中"的完整闭环。
- **一般号召与个别指导相结合**：试点与推广的领导技术；本 skill 是意见循环上升的程序。
- **让人讲话（三不主义、先民主后集中）**：决策前的心理安全；本 skill 是贯穿全程的群众意见循环。
