# 一般号召与个别指导相结合（试点先行·抓两头带中间）

## R — 原文 (Reading)

> "任何工作任务，如果没有一般的普遍的号召，就不能动员广大群众行动起来。但如果只限于一般号召，而领导人员没有具体地直接地从若干组织将所号召的工作深入实施，突破一点，取得经验……就有使一般号召归于落空的危险。"
>
> — 毛泽东，第三卷《关于领导方法的若干问题》

---

## I — 方法论骨架 (Interpretation)

- 推广一件新事，先要有"一般号召"——把目标、框架向全局发出，动员大家动起来；没有号召，无法发动。
- 但只有号召会落空：领导必须**亲自**选少数几个单位，扎下去把这件事做通，突破一点、取得经验。
- 这几个典型**要少**（原文说"二、三个单位，不要很多"），重点不是树样板，而是用它来**考验并充实**原来的号召——原号召是否可行、哪里要改。
- 拿到经验后**波浪式、分阶段**推广，不企图一蹴而就；不是一次性全面铺开。
- 同时"抓两头带中间"：抓住做得最好的和做得最差的两个极端作着力点，用它们带动占多数的中间状态。
- 核心张力：号召要普遍，落实要个别；没有个别指导的号召是空的，没有一般号召的个别经验无法推广。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1942 年整风经验——一般号召与个别指导相结合
- **问题**: 只发一般号召，易使号召落空；只做个别指导，又无法向全局推广。
- **方法论的使用**: 作者据 1942 年整风的成败经验（"凡有成绩者，都是采用了一般号召和个别指导相结合的方法；凡无成绩者，都是没有采用此种方法"），规定 1943 年必须在机关、学校、部队中"选择二、三单位（不要很多）"，深入研究、取得经验，再据以考验并充实一般号召。
- **结论**: 提出"一般号召与个别指导相结合""领导骨干与广大群众相结合"两条基本方法。
- **结果**: 把典型单位的具体经验作为普遍指导的依据，纠正了停留在嘴上、纸上、会议上的空号召。（c12，第三卷《关于领导方法的若干问题》）

### 案例 2: 新解放区土改的分阶段、波浪式推进
- **问题**: 新区土改牵涉面广、情况不一，若急于短期内一次性完成，容易出偏差。
- **方法论的使用**: 作者规定"不要性急"，新区土改分两个阶段（先打击地主、中立富农，再平分土地），每阶段又分几个步骤、区别对待，把推进做成波浪式而非一蹴而就。
- **结论**: 应按环境、群众觉悟程度和干部强弱决定推进速度，"准备在两三年内完成全区的土地改革"。
- **结果**: 形成分阶段、波浪式、区别对待的推进方案。（第四卷《新解放区土地改革要点》）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司要在全国数百家门店/多个团队推行一套新制度或新流程。
2. 一款新工具、新规范要向全组织推广，纠结一刀切还是分批。
3. 一项改革要落地，担心"上面发个文，下面不了了之"或执行走样。
4. 带团队时既要抓做得好的标杆，又要处理拖后腿的，还要带动中间多数。
5. 已有初步方案，想先小范围验证取得经验再全面推开。

### 语言信号 (用户的话里出现这些就应激活)

- "全国推广""一刀切""先试点还是直接铺开""怎么落地不走样""怎么推广最稳""先在小范围试试"
- "怎么带动中间那批人""抓先进还是抓落后""要不要先做样板"
- EN: "roll out to all units / pilot first then scale / one-size-fits-all / wave-like rollout / how to roll out safely / grasp both ends to move the middle"

### 与相邻 skill 的区分

- 与 `mass-line`（群众路线）的区别: 后者是"从群众中来、到群众中去"的**意见循环**；本 skill 是"号召—试点—推广"的**推进/领导技术**，重心在推广节奏与典型选择。
- 与 `narrow-target`（缩小打击面、区别对待）的区别: 后者讲处置一批对象时的**比例约束**；本 skill 讲推进一件新事时的**试点与推广节奏**（虽同样含"分阶段、波浪式"）。
- 与 `investigation-method`（调查研究法）的区别: 后者是推广前的取证；本 skill 是拿到初步认识后的落地与扩散。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **先发一般号召**
   - 完成标准: 写出面向全局的号召/框架——目标、范围、时间要求，能让人据此动起来。

2. **选二三个典型单位（要少）**
   - 完成标准: 明确选定 2–3 个有代表性的单位（不要很多），并说明它们为何有代表性。
   - 判停条件: 若环境高度异质、2–3 个样本明显不足 → 停，扩大样本或先说明外推的适用条件。

3. **亲自深入、突破一点取得经验**
   - 完成标准: 由负责人本人扎下去把这几个单位做通，拿到可复制的经验与做法，而非只发指示、听汇报。

4. **用经验检验并充实原号召**
   - 完成标准: 指出原号召哪些可行、哪些需修改，形成修订后的号召内容。
   - 判停条件: 若经验表明号召方向本身错误 → 停，先修正方向再推广。

5. **波浪式、分阶段逐步推广**
   - 完成标准: 给出分批/分阶段的推广安排，而不是一次性全面铺开；每批总结经验后再推下一批。

6. **抓两头带中间**
   - 完成标准: 明确抓住做得最好的与最差的两头各做什么，并说明如何借此带动中间多数。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 环境高度异质，"二三个样本不具代表性"时，直接外推会失真，应先扩大样本或限定适用范围。
- 只做一次、无需向其他单位推广的单一任务，谈不上号召与推广。
- 把"试点"异化为"树样板""造政绩"：只挑最容易出成绩的点做样子，失去"检验号召"的本意。

### 作者在书中警告的失败模式

- **政策和策略上"左"的偏向、工作步骤上的急性病**：急于求成、企图一蹴而就，忽视分阶段波浪式推进（第四卷《关于情况的通报》，ce24）——正是"不要性急、波浪式推进"要纠正的反面。
- 注: 本单元在 units-merged 中无专属 counter-example（相关反例为"—"），以上取与本方法最直接相关的作者所警告失败模式（ce24）。

### 作者的盲点 / 时代局限

- 典型的"代表性"依赖先验判断，**选错样本即从个别误推一般**；"选二三个就够"在高度异质对象上会失真（units-merged u33 风险提示）。
- 试点成功能否外推依赖可比性，原文未给外推条件（同上）。
- 由个别经验上升为一般规律，存在以偏概全、以成功案例反推普遍性的风险（BOOK_OVERVIEW §3 论证链归纳特征）。
- 第六卷《工作方法六十条（草案）》出自**静火版非官方汇编、记录稿，可靠度较低**（BOOK_OVERVIEW §3 时代局限 4）。

### 容易混淆的邻近方法论

- **群众路线（从群众中来到群众中去）**：意见循环；本 skill 是推广节奏与典型选择。
- **缩小打击面，区别对待**：处置比例约束；本 skill 是推进新事的分阶段落地。
