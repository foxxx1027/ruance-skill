# 感性材料加工四法（去粗取精·去伪存真·由此及彼·由表及里）

## R — 原文 (Reading)

> "将丰富的感觉材料加以去粗取精、去伪存真、由此及彼、由表及里的改造制作工夫。"
>
> — 毛泽东，《实践论》（第一卷）

---

## I — 方法论骨架 (Interpretation)

- 手里有一堆材料（访谈、数据、反馈、观察），不等于已经有了认识。
- 感觉材料要经过四道有次序的"改造制作"工序，才能变成概念和判断：
- **去粗取精**——剔除与要解决的问题无关的材料，只留精要。
- **去伪存真**——分辨真假：哪些是真实需求或事实，哪些是情绪化、不实或误导之词。
- **由此及彼**——把原本孤立的材料联系起来，找出彼此的因果与相关。
- **由表及里**——透过表层现象，抓住事物内部的本质。
- 关键是这四步是有次序、须逐一执行的流程，而不是笼统的"多想想、仔细点"。
- 走完四步，输出应是概念与判断（本质是什么、事情如何关联），而不是现象的罗列。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 延安考察团"想了一想"（从感性到理性）
- **问题**: 外来者初到延安，只看到一地零碎现象，无法直接得出结论。
- **方法论的使用**: 先经看地形、屋宇、宴会、谈话、文件等取得感性材料，再用"想了一想"（判断推理）加以加工改造。
- **结论**: 由感性认识上升到理性认识，作出"共产党的抗日民族统一战线的政策是彻底的、诚恳的和真实的"这一判断。
- **结果**: 说明认识须经两次飞跃，感觉材料必须经过加工才能成为判断。（c02）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 刚做完一批用户访谈或收到一堆反馈，材料杂乱，用户问"这些到底说明什么"。
2. 手里有大量数据/材料，但只在罗列现象，想要一个固定的加工顺序把材料变成洞察。
3. 面对混杂着真实诉求与情绪化言论的信息，需要分辨"哪些是真需求"。
4. 想从一堆具体现象里抽出背后的本质或规律，而不是停在描述。

### 语言信号 (用户的话里出现这些就应激活)

- "一堆反馈怎么变成洞察""信息太杂怎么梳理""材料很多但理不出头绪"
- "哪些是真需求""怎么分辨真假信息""怎么透过现象看本质"
- turn raw feedback into insights / too much noise to make sense of
- real need vs noise / see through to the essence / how do I synthesize this

### 与相邻 skill 的区分

- 与 `practice-cognition-loop` 的区别: 本 skill 是那个循环里"第一次飞跃"内部的四道具体工序；后者是覆盖两次飞跃与反复循环的整体框架。
- 与 `investigation-method` 的区别: 后者负责"取到材料"；本 skill 只负责"材料到手后的加工"。材料不足时应先回到后者。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **去粗取精**
   - 完成标准: 逐条筛掉与目标问题无关的材料；留下的每一条都能说明它与目标问题的关联。

2. **去伪存真**
   - 完成标准: 对存疑材料标出证据等级（一手/二手、可否核实）；剔除或明确标记不实、情绪化、来源不可靠的信息。

3. **由此及彼**
   - 完成标准: 至少形成 1 条把材料 A 与材料 B 联系起来的因果或相关判断（不是并列罗列）。

4. **由表及里**
   - 完成标准: 输出一句话的本质判断（概念/规律），而非现象清单。
   - 判停条件: 若四步走完仍拿不出判断（材料太薄）→ 回到 `practice-cognition-loop` 或 `investigation-method` 补取材料。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 材料本身不足时——四道工序加工不出不存在的材料，应先补调查（走 `investigation-method`）。
- 已成定论、无争议的事实汇总，或纯数字抄录，不需要辨伪与找联系。
- 低风险、结论显而易见的简单汇总。

### 作者在书中警告的失败模式

- **开中药铺**：按事物的外部标志罗列现象、不分析内部联系，"使人不用脑筋想问题……满足于甲乙丙丁的现象罗列"，是"最低级、最幼稚、最庸俗"的方法（第三卷《反对党八股》，ce22）。这正是"由此及彼、由表及里"要治的病。
- **主观性、片面性、表面性**：只看见局部与现象、不看见全体与本质（第一卷《矛盾论》，ce07）。

### 作者的盲点 / 时代局限

- 四法为思维工序描述，缺少可操作判据；"精/伪/彼/里"的界线依赖判断者自身能力。
- 如何判定"已抓到的本质"确为本质、而非另一种表象，原文未给独立准则。

### 容易混淆的邻近方法论

- **实践—认识循环（`practice-cognition-loop`）**：四法是其第一次飞跃内部的具体工序。
- **分析—综合四步法（反对开中药铺）**：那是"提出问题→分析→综合→给办法"的问题处理流程，比本 skill 的四道加工工序更前置一层。
