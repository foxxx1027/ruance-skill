# 既联合又斗争（以斗争求团结·有理有利有节）

## R — 原文 (Reading)

> "以斗争求团结则团结存，以退让求团结则团结亡"；"有理有利有节"。
>
> — 毛泽东，第二卷《目前抗日统一战线中的策略问题》《论政策》

---

## I — 方法论骨架 (Interpretation)

- 与长期伙伴/盟友合作，不能靠一味退让来维持关系——无原则的退让反而会让联盟瓦解（"以退让求团结则团结亡"）。
- 正确做法是"既联合又斗争"：既保持合作，也维护自己的独立立场与核心利益；把必要的分歧表达与博弈，当作**达成更稳固合作的手段**，而不是目的。
- "斗争"必须上三道锁：
  - **有理**：出于正当防卫、维护明确的权益，不主动挑衅；
  - **有利**：有把握、不做无胜算的对抗；
  - **有节**：见好就收、适可而止，不把冲突无限升级。
- 目的始终是"团结"（维持关系）；冲突只是防止关系被单方侵蚀而破裂的手段。
- 联盟中还要保持独立：不因合作而丧失自主性，避免被对方同化或吞并。
- 常见误用：或把团结理解为回避斗争、一味退让；或反向地把斗争无限制使用——两种都会毁掉联盟。

## A1 — 书中的应用 (Past Application)

### 案例 1: 联盟合作中"既联合抗日又保持独立、斗争讲分寸"
- **问题**: 建立合作联盟后，如何处理与伙伴的关系——一味退让会被逐步吞并，过度斗争又会把联盟搞破裂。
- **方法论的使用**: 作者提出"以斗争求团结"，对强硬方的进攻作"有理、有利、有节"的自卫斗争，同时在联盟中坚持独立自主；在就和平谈判发出的通知中，强调斗争须有限度、有把握。
- **结论**: 斗争是达成团结的手段，须以"正当理由、胜算、节制"为边界；联盟中要保持独立。
- **结果**: 既维持了合作联盟，又避免被吞并与无限制对抗（出处：第二卷《目前抗日统一战线中的策略问题》《统一战线中的独立自主问题》；第四卷《中共中央关于同国民党进行和平谈判的通知》，及 ce16 所述反面）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 与长期合作伙伴 / 供应商 / 合资方出现利益冲突，纠结"该忍让还是撕破脸"。
2. 联盟或团体里有人不断越界、侵蚀你的利益，不确定要不要公开表态。
3. 谈判中对方提出不合理条件，纠结是接受、拒绝还是反制。
4. 跨团队协作中，另一团队抢资源/推责任，如何既维持合作又捍卫边界。
5. 担心"一旦强硬就会把关系搞僵"，因而长期让步、积压不满。

### 语言信号 (用户的话里出现这些就应激活)

- "该让步还是翻脸""忍了还是撕破脸""不想撕破脸但又咽不下这口气"
- "一直让步反而被得寸进尺""怎么既合作又守住边界"
- "EN: assertiveness vs accommodation, stand your ground, fight for unity, measured confrontation, hard on issues soft on relationship, push back without breaking the relationship"

### 与相邻 skill 的区分

- 与 `统一战线三分法`(u26) 的区别: u26 是"尚未结盟的多方分层争取"；本 skill 是"已结盟伙伴之间的既合作又守边界"。
- 与 `针锋相对，寸土必争`(u30) 的区别: u30 讲对等回应、核心利益不让（面向对手）；本 skill 讲在联盟内部为维持关系而控制冲突的限度（有理、有利、有节）。
- 与 `独立自主`(u52) 的区别: u52 讲联盟中保持独立；本 skill 讲独立之外还主动用分寸得当的"斗争"来维护关系。
- 与 `缩小打击面，区别对待`(u31) 的区别: u31 讲缩小出手范围防扩大化；本 skill 讲冲突要"有节"、见好就收。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判断冲突性质**
   - 完成标准: 明确这是"联盟内的利益摩擦"还是"根本性对抗"，并写清你是否**仍然想维持**这段合作（目的=团结）。
   - 判停条件: 若确定要结束关系，退出本 skill，转"针锋相对/丢掉幻想"类方法。

2. **明确要维护的具体权益（有理）**
   - 完成标准: 能说清"我维护的是哪一条明确权益、我为何是正当的"，而非情绪化不满；确认不主动挑衅。

3. **评估胜算与手段（有利）**
   - 完成标准: 给出有把握的具体做法（证据、筹码、时机）；若毫无把握，改为暂缓并先积累筹码。

4. **设定停止点（有节）**
   - 完成标准: 事先写清"达到什么结果就收手"，并约定不升级的红线（不攻击人格、不扩大到无关议题）。

5. **行动后回到合作**
   - 完成标准: 冲突解决后主动恢复常态协作，使"团结"这个目的真正落地。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 平等、低利害、一次性的协作——硬要"斗争"会无端制造对抗。
- 亲密/信任型关系（家人、挚友）——用博弈框架处理会伤害关系。
- ⚠️ **滥用警告**：把"斗争"当默认手段、把对方"妖魔化"、把正常分歧"无限上纲"为敌我矛盾——会侵蚀信任、把可控摩擦升级为不可逆的冲突。本 skill 的前提是"目的仍是团结"；一旦目的从"团结"变成"打倒对方"，就已越界。

### 作者在书中警告的失败模式

- **无原则退让 / 无限制斗争**（第二卷《目前抗日统一战线中的策略问题》，ce16）：把团结理解为回避斗争、一味退让，则会被对方逐步侵吞；反过来把斗争无限制使用，又会把联盟搞破裂。成因是不懂"斗争是手段、团结是目的"，把手段与目的割裂或倒置。
- **宗派主义**（第三卷《整顿党的作风》，ce19）：对外排外性会妨碍团结多数。

### 作者的盲点 / 时代局限

- 假定冲突升级始终可控（"有节"能收束），但**未证明**（BOOK_OVERVIEW §3 未证明假设 2）。
- 以"斗争"为默认手段，在长期合作关系中可能侵蚀信任（units-merged u27 风险提示）。
- 以立场归属而非论证本身给异议定性，存在以标签替代论证的循环（BOOK_OVERVIEW §3 立场盲点 4）——政治斗争语境须做语境剥离后再迁移。

### 容易混淆的邻近方法论

- 统一战线三分法（多方分层争取）；针锋相对，寸土必争（对等回应对手）；独立自主（联盟中保持独立）；缩小打击面，区别对待（收窄出手范围）。
